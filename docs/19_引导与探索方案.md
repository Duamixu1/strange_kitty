# 19 引导与探索方案（游览版）

11-05 你说："整体体验感比较差，地图里的交互性和引导比较少；一方面要让人自由探索，一方面要给钩子让他知道怎么玩。"
这份是方案，**先拿坂井家做样板**，你看过再动手。要你拍板的地方集中在最后一节。

## 一、现在的问题在哪

东西其实不少：観点和说明卡、配角走动换姿势、随机物怪、药箱收集（n / 11）、拍照、拔剑。问题是**它们之间没有连起来**：

| 现在 | 玩家的感受 |
|---|---|
| 说明卡是纯介绍（"这是客间，坐垫颜色压得很重"） | 看完不知道接下来干什么，也不知道为什么要看下一张 |
| 物怪 40~80 秒后随机出，第一只一定是原作那只 | 跟逛没关系，像被打断；化猫在门前就出了，故事还没铺就打完了 |
| 形、真、理靠打斗里投札钉中三次得到 | 形真理成了按键结果，不是"查出来的" |
| 配角不说话 | 像摆设，没有人可以问 |
| 走过哪间、看过哪张，没有任何记录 | 不知道自己逛完没有，也没有"还差一点"的牵引 |
| 门只是出口 | 不知道哪扇门后面有东西 |

## 二、核心思路：给目标，不给路线

**每个地点是一个小案子：查出这里物怪的形、真、理。**

- 线索散在各个房间：観点、配角的话、藏起来的小物件。先找哪个都行。
- 三样都查到，原作那只物怪才现身（"本命"遭遇），在故事该出现的房间里出。
- 其他物怪（变体、新四只）照旧随机出，当作路上的小插曲。

逛有了理由，打斗成了逛完的高潮。拔剑时那三格"还差几样"已经有了，现在让它们在探索里一格一格亮起来。

## 三、坂井家样板：线索放在哪

文案线已经写好的形真理（text.json `mononoke.sakai`）正好能拆到三个房间：

| 字 | 那句话 | 线索在哪 | 怎么拿到 |
|---|---|---|---|
| 形 | 一只猫都没有的家里，出了化猫。 | 厨房与后院 | 看"没有猫的厨房"観点 + 问女中加世（"这家不许养猫，老爷说的"） |
| 真 | 多年前，有个女子被关进这宅子深处。 | 密室 | 看"藏着白无垢的房间"観点 |
| 理 | 她死在那里，她的猫记住了这一家人。 | 屋后古井 + 客间 | 看"屋后的古井"小坟 + 问老家主伊行（问过两样才亮"理"） |

- 每拿到一样，屏幕中间轻轻浮出一个红字（形 / 真 / 理），右上角小三格亮一格。
- 三样齐了：天秤剧烈一抖，铃声从婚礼大座敷方向传来，门前那条提示写"铃声是从大座敷来的"。
- 化猫在**婚礼大座敷**现身（场景线已经标了 4 个出生点）。打法不变，投札三次、拔剑。区别是钉中时浮出的那三句，玩家这时已经自己查到了。
- 打完掉"生锈的猫铃"，魂走那句照旧。地图上坂井家盖"退魔"红印。

门前、玄关、红色廊下、婚礼大座敷不放形真理线索，放"气氛线索"（见第五节第 3 条），把人往里引。

## 四、怎么引导：游戏里的东西指路，按时间往上加

不出现箭头、小地图标记、任务列表。

**1. 天秤当指南针**
- 药郎身边的天秤（现在只在物怪预兆里抖）平时也挂着。它朝**这个区块里还没看过的线索**微微倾，离得越近晃得越快。
- 区块里没东西了就停住不动，意思是"这里查完了"。
- 手机上同样能看到，不占按钮。

**2. 门上贴札**
- 通往"还有没拿的线索"的拉门，门框上贴一张淡淡发光的札。
- 去过、查完的门，札变暗、颜色褪掉。
- 这是区块之间的引导，告诉你往哪扇门走。

**3. 按时间往上加的提示（同一个区块里，多久没找到新东西）**

| 多久没找到 | 给什么 |
|---|---|
| 0~40 秒 | 什么都不给，自己逛 |
| 40 秒 | 环境暗示：铃声从线索那边传来、那边的灯笼亮一下 |
| 90 秒 | 一只小化猫从画面边上跑过去，在线索旁停下回头看，然后消失 |
| 150 秒 | 提示条直接写一句（"厨房那边好像有什么"） |

找到一样就重新计时。会找的人根本碰不到后两档。

- 11-05 角色线：小化猫模型 `bakeneko_posed.glb` 加了 `run_k`（原地小跑循环，一圈 0.42 秒，root 往前走 2.4 米/秒 × 缩放脚不打滑）和 `look_back_k`（1.17 秒，停稳、往它自己的左后方回头约 110°、转回前方）。逐帧图 `shots/小化猫_领路_小跑和回头.jpg`。

**4. 第一次进来的三分钟**
- 门前只有一个観点，提示条直接写"E 看看 · 办喜事的门楼"。
- 看完那张卡，结尾的疑问把人引进门（见第五节第 3 条）。
- 进门以后第一次靠近天秤在倾的方向，弹一句"天秤在往那边歪"。只弹一次，后面都不教。

## 五、怎么让人想继续逛

**1. 配角开口**
- 走近 2 米内，配角头上冒一句话（纸条样式，3 秒消失）。按 E 能再说一句。
- 每个配角 2~3 句，有一句带线索。不做对话树。
- 坂井家：若党小田島、老家主伊行、女中加世。大奥和万屋后面照样做。

**2. 完成感**
- **区块查完盖印**：这个区块的线索都拿到了，画面右上角盖一个小红印"查毕"。
- **总地图进度**：每个地点下面写"形真理 2 / 3 · 物怪 1 / 4 · 観 6 / 8"。
- **差一点时提醒**：观点看了 7 / 8，进那个区块时提示条写一句"这里还有一处没看"。

**3. 说明卡结尾留疑问（文案线）**
现在的卡是介绍；改成最后一句是疑问，并且指向别的房间。例子（只是方向，用词交给文案线）：
- 门前："……门前比平时热闹得多。可是这么大的宅子，怎么一声猫叫也没有？" → 引到厨房
- 红色廊下："……越往里走越长。尽头那扇门，下人们都绕着走。" → 引到密室
- 客间："……老家主一直盯着屏风上的鹤，像在等谁回来。" → 引到伊行的话、古井

**4. 给好奇心的奖励（不算主线）**
- 每个地点藏 2~3 个"拾遗"：角落里的小物件，拿到只是收进药箱"拾遗"那一格，不影响形真理。
- 拍照点：站到某些位置，拍照钮边上闪一下，拍出来带一个落款印。
- 这些给喜欢翻的人，赶路的人不受影响。

## 六、随机物怪怎么调

| | 现在 | 改成 |
|---|---|---|
| 第一次遭遇 | 40~80 秒，一定是原作那只 | 原作那只改成"本命"，要形真理齐了才在固定房间出。第一次随机遭遇改成别的（坂井家出小化猫，正好跟"没有猫"的故事呼应） |
| 随机出的时机 | 进地点 40~80 秒 | 至少看过两张卡再出，避免还没逛就被打断 |
| 本命打完以后 | — | 随机照旧，冷却 2~3 分钟，"怪"开关不变 |

## 十、斩与送（11-05 你说"小猫看起来很可爱，X 斩杀有一种直接把它杀了的感觉，很可怕"）

### 原作里剑斩的是什么

原作的说法：物怪是"妖"和人的情念（怨、悔、执着）缠在一起变成的。退魔剑要知道形、真、理才拔得出来，**斩的是缠在上面的那份情念**，不是把妖本身剁了；斩完以后，留下的东西是解脱了、走了。剑自己会判断：条件不对，剑就不出鞘。

我们现在的画面是：剑横斩 → 物怪本体播"消散"动作、化墨溅开。看起来就是把那只猫砍死了。这和原作的意思是反的。

### 改成两种收场，剑自己决定用哪种

| | 斩怨（有怨的） | 送（没有怨，只是在等、在想） |
|---|---|---|
| 哪些 | 化猫、座敷童子、唐伞（三只本命）、黑唐伞、无面、火鼠、海坊主、鵺 | 小化猫（等人喂）、白化猫（想回家）、青座敷（想有人来找他玩） |
| 按键 | X（不变） | X（同一个键）；手机上那颗钮的字从「斩」变成「送」 |
| 剑 | 拔剑，照旧妖化、金描边、运镜 | **剑不出鞘**。第一次会弹一句"剑没有动 · 它没有怨"，之后不再弹 |
| 药郎的动作 | 现有退魔（完整 10 秒 / 短版 3 秒） | 新的「送」：结印 → 一张札贴地 → 退一步，静静看着它走（先用现成的 seal_k + settle_k 接，角色线再做一段正式的 okuri_k） |
| 画面 | **怨念剥离**：妖化那一刻，一团黑墨从它身上被抽出来，浮在它上方，成了一团有面具的墨影（就是原来占位物怪的样子）；它本身慢慢褪成浅色、不再张牙舞爪。横斩**斩的是那团墨**：墨被劈成两半、烧成金色火星散掉。剩下的它化成魂光升起 | 札阵落到地上变成一圈光；黑墨像水一样从它身上往下滴干净，它褪成浅色，抬头看药郎一眼，化成魂光走。小化猫是远处先亮起母猫的光，三只跟过去（现在的魂走已经是这样） |
| 物怪本体播什么 | 不再播"消散"（vanish_k），改成待机慢慢淡成光 | 待机 → 淡成光 |
| 声音 | 照旧拔剑、横斩，斩到墨团时加一声"嗤"的烧纸声 | 不拔剑：一声铃、一声纸落地，BGM 收小 |
| 卡片 | 执念物卡照旧 | 执念物卡照旧（三只小铃那句本来就是"被母猫接走了"） |

- 两种收场都留"魂走那一句"（text.json 的 after），文案不用改。
- 哪只走哪种写在 `encounter.js` 的 MONO 表里（`okuri: true`），以后想换一行就改。
- 剑不出鞘这一下也是原作味道：退魔剑会自己判断要不要出来。

### 分工

- 总指挥：怨念剥离（墨团从本体抽出、劈开、烧散）、本体褪色淡成光、"送"的整套流程和特效、手机钮换字、自测。
- 角色线：药郎「送」一段正式动作 okuri_k（约 4 秒：结印、单手把札放到地上、直起身退半步、垂眼目送，最后收手；动作要静，跟退魔的气势反着来）。不花积分。

## 十一、做成什么样了（11-05，总指挥）

**代码**：新文件 `web/src/tour/guide.js`（引导与探索），改了 `tour.js`（接引导、拾遗小物件、拍照落款印、总地图进度）、`encounter.js`（斩怨 / 送、本命、随机规则）、`mononoke_fx.js`（怨念剥离、劈开、滴墨、札阵落地）、`style/toon.js`（褪色 uPale）、`audio.js`（烧纸、送）、`tour.html`（右上三格、浮字、查毕印、冒话纸条、门札、拾、拍照点）。

**数据格式**：
- 地点 JSON 的 `case`：`mononoke`（本命）、`boss`（本命在哪个区块出）、`firstRandom`（本命之前第一次随机出的）、`npcNames`、`clues: [{ char, need: ["区块/view:観名", "区块/npc:配角 id"] }]`。坂井家：形 = 厨房観1 + 加世；真 = 密室観1；理 = 古井観2 + 伊行。
- 区块：`finds: [{ id, pos, y, kit }]`（场景线 find_candy / find_claw / find_bowl）、`photo: [{ pos, r, yaw }]`、`bossAt: [x, z]`。
- text.json：`case.<地点>`、`npc.<地点>.<id>`（lines + clue 下标）、`hint.<地点>.<字>`、`find.<地点>.<id>`（文案线 11-05 写好坂井家，8 张卡结尾也改成了疑问）。

**规则**：
- 进度存浏览器本地 `mononoke_tour_case_<地点>`：看过 / 听过 / 捡过的、亮了哪几个字、哪些区块盖了查毕、本命退了没有。
- 天秤朝区块里最该找的那样东西倾（先找跟没亮的字有关的，再找近的），越近晃得越快，区块查完停住。
- 门札：隔壁没去过或没查完 → 发光的札；查完 → 门牌褪色；形真理齐了以后本命那间 → 朱红的札一跳一跳。
- 提示：只在能自由走的时候计时，找到一样就重来；40 秒那边亮一下 + 铃，90 秒一团小光从药郎身边飘过去停在那儿（小化猫领路的动作到了再换成小化猫），150 秒提示条写 hint 那句（没写的用"这里还有一处没看"之类）。
- 配角：走近 2 米冒第一句（每进一次区块一次），E 依次说下一句；说到 clue 那句才算听到。
- 物怪：看过两处才随机出；本命没退之前随机不出它，第一次随机出 firstRandom（坂井家小化猫）；形真理齐了走进本命区块 2.5 秒后它在 bossAt 现身，"怪"开关关着也出；退了盖"退魔"。
