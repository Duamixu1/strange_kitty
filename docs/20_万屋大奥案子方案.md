# 20 万屋、大奥的案子方案（游29 往下套）

11-05 你说："你同步给出修改大奥和另外一个场景的修改细节方案"。这份是把坂井家那一套（docs/19）套到**万屋**（座敷童子）和**大奥**（唐伞）上的细节方案。
你在坂井家走第二圈的感觉要是有改动，这里跟着改。要你拍板的地方都放在最后一节。

---

## 一、从坂井家学到的几条规矩（两个地点都照这个做）

| 坂井家试玩发现的问题 | 万屋、大奥一开始就这样做 |
|---|---|
| 有坟的房间"没有任何线索或交互" | **放了线索的房间，至少有一样能"做"的事**（合掌、侧耳听、往井里看、打开柜子），不能只有一张说明卡 |
| 厨房看不见捕鼠夹 | **卡里写到的东西，画面里一定看得见**：文案先列"卡里提到的物件"，场景线逐条摆，总指挥逐张截图对 |
| 先进了大座敷，顺序乱了 | 每个地点都排一遍**先后**：哪个字要等哪个字（`after`），本命那间提前进去浮一句（`pre`） |
| 线索要能收进药箱 | 每个地点一张**宅图格子表**（`case.plan`）和全套**摘记**（`note.<地点>`） |
| 走出房间回不去 | 代码已修（所有地点通用），新地点照样跑"一进门就转身往回走"那项自测 |

每个地点的配置清单都一样：
- `case`：本命、本命出在哪间、第一次随机出哪只、形真理各要哪几样、先后顺序、宅图格子表。
- 区块：`acts`（能做的事）、`finds`（拾遗 3 件）、`photo`（拍照点 2 个）、`bossAt`（本命出生点）。
- 文案：卡片结尾改成疑问、配角 2~3 句、`hint` 三句、`hold` 一句、`pre` 一句、`act` 的那句、`find` 三张、`note` 摘记、`case.<地点>` 开场卡。

## 二、万屋（座敷童子）

**原作线索**：雨夜，一个怀孕的女子（志乃）来投宿，被领进顶层那间不给客人住的大座敷。这楼以前是妓楼，那些年里有孩子没能生下来，他们就是满屋跑的座敷童子。他们想出生，想有一个肯要他们的娘。

**本命**：座敷童子，在**大座敷**（顶层）现身。
**第一次随机出**：青座敷（它走"送"的那条，第一次碰到就不是斩，和这一篇的气氛合得上）。

### 线索怎么排

| 字 | 那句话（text.json 原有） | 线索在哪 | 能做的事 |
|---|---|---|---|
| 形 | 满屋跑来跑去的，是座敷童子。 | 二楼长廊：**侧耳听**（新 act）+ 门厅：番头德次的话（"楼上没住小孩，可夜里总听见有人跑"） | 侧耳听：药郎停下抬头，楼板上一串小脚步从头顶跑过去，镜头微微一抖，廊下尽头一个小黑影一闪就没了 |
| 真 | 这楼做妓楼的年月，有孩子没能生下来。 | 室内庭：庭石的观（原有 niwa.2）+ **庭石后面的小地藏**（新 act，"合掌"）+ 门厅：老板娘久代的话（话里有话，不说透，比如"这楼以前做什么的，客人就别问了"） | 合掌：庭石后面藏着几尊系红围兜的小地藏，药郎合掌，旁边一只风车转起来 |
| 理 | 他们只想出生，想有个肯要他们的娘。 | 大座敷：观（原有 ozashiki.1）+ 志乃的话（"这孩子，我一定要生下来"） | 和志乃说话就是这一步 |

- **先后**：理要等真（`after: "真"`）。不知道"没能生下来"，"想出生"那句接不上。
- **本命那间提前进去**：大座敷浮一句（`pre`），意思是顶楼有小孩的笑声，一靠近就停了。
- **拾遗 3 件**：门前红桥边一只小草鞋；二楼长廊襖下沿一个很矮的小手印；门厅账台上一只没人认领的拨浪鼓。这三样都是"小孩"的东西，但不点破。
- **拍照点**：雨夜门前过红桥看唐破风；室内庭红拱桥。
- **见闻**：门前三个观、门厅彩色玻璃门、八角厅、室内庭第一个观。

### 宅图格子表（两层楼画成一张剖面，往上是楼上）

| 区块 | 格子 [列, 行, 跨列, 跨行] | 贴图（暂定，场景线可换） |
|---|---|---|
| 大座敷（顶层） | [2, 1, 3, 2] | tatami.png |
| 二楼长廊 | [1, 3, 3, 2] | boards.png |
| 室内庭 | [4, 3, 2, 2] | gravel.png |
| 门厅 | [2, 5, 3, 1] | glassdoor.png |
| 雨夜·门前 | [1, 6, 5, 1] | deck.png |

装饰格：[1, 1, 1, 2] 写"楼梯"。右上角写"↑ 楼上　↓ 门前"（要加一个 `compass` 字段，代码我来改）。

### 各条线要做的

- **场景线**：
  1. 二楼长廊：襖下沿几个小手印（拾遗那个要单独一个，摆得更隐蔽）。侧耳听的站位写进 `acts`。
  2. 室内庭：庭石后面一排小地藏（红围兜）、一只纸风车，合掌站位写进 `acts`。
  3. 拾遗 3 件小积木（小草鞋、手印、拨浪鼓）。
  4. 两个拍照点。
  5. 大座敷的 `bossAt`（志乃站的位置附近要留出空地，别让物怪贴着她冒出来）。
  6. 卡里写到的东西逐条对一遍。
- **文案线**：
  1. 6 张卡结尾改成疑问，往"楼上有什么""这楼以前是什么地方"引。
  2. 德次、久代、志乃各 2~3 句（clue 标上）。
  3. hint、hold、pre 各一句。
  4. act 两句：侧耳听、小地藏合掌。
  5. find 三张、note 摘记、开场卡。
- **角色线**：侧耳听先用现成的 look_up_k（抬头）。小黑影一闪不用模型，我用墨影。不花积分。
- **总指挥**：
  1. act 加三样：动作名、效果类型（脚步声 + 小黑影 / 风车转 / 线香）、镜头一抖。
  2. 宅图的 `compass`、楼梯装饰格。
  3. 两条自测。

## 三、大奥（唐伞）

**原作线索**：新进大奥的女中，要把带来的心爱之物丢进中庭那口井，算是和外面断了。被丢下的那些东西和心思不肯沉下去，聚成了唐伞。大奥的规矩由年长的御年寄（歌山）管着。

**限制**：大奥五个区块都是实景扫描（泼溅），墙和地动不了。加东西只能另外摆小积木叠上去（拾遗那种做法），场景线要看叠上去和扫描画面搭不搭。四间小房间转不开，不出物怪，本命只能在**主廊**出。

**本命**：唐伞，在**主廊**现身。主廊也是起点，所以不在第一次进来时出，要等形真理齐了、从哪间房出来回到主廊时才出。
**第一次随机出**：火鼠（大奥这三只都走"斩"，火鼠和唐伞不像，不会抢本命的戏）。

### 线索怎么排

| 字 | 那句话 | 线索在哪 | 能做的事 |
|---|---|---|---|
| 形 | 雨里自己撑开的，是一把唐伞。 | 主廊：**墙边收着的一把旧唐伞**（新 act，"看看"）+ 女中房：阿龟的话（"廊下那把伞，没人碰它自己就撑开了"） | 看伞：药郎走近，伞"啪"地自己撑开半圈，又慢慢合上，一点雨声 |
| 真 | 进大奥的人，都把自己的一部分丢进了井。 | 中庭：观（原有 courtyard.1，卡里已经写了丢井的规矩）+ **往井里看**（新 act）+ 女中房：阿浅的话（"我带来的那面小镜子，也得丢进去吗"） | 往井里看：药郎俯身，井水里浮起几样东西的影子（梳子、信、小人偶），一晃就散了 |
| 理 | 被丢下的那些，不肯就这样沉下去。 | 阿雪的空房：观（原有 yuki.1）+ **打开柜子**（新 act）+ 歌山房：歌山的话（"丢了就是丢了，谁也不许去捞"） | 打开柜子：空房的壁橱里，摆着一排湿漉漉的东西，像是从井里自己回来的 |

- **先后**：理要等真。
- **本命那间**：主廊是起点，不用 `pre`。改成形真理齐了以后，四间小房的门札全部变成"回主廊"的那张朱红札，回到主廊就出。
- **拾遗 3 件**：主廊地上一根掉落的发簪；女中房圆窗下一只折纸鹤；歌山房文机上一封没写完的信。
- **拍照点**：主廊看红白扇面门洞；女中房圆窗。
- **见闻**：主廊两个观、女中房、歌山房的观。

### 宅图格子表（一条长廊，四间房挂在两边）

| 区块 | 格子 | 贴图（暂定） |
|---|---|---|
| 女中房 | [1, 1, 2, 2] | fusuma_hana.png |
| 歌山房 | [1, 4, 2, 2] | byobu_shoukaku.jpg（整幅，只铺一张） |
| 大奥主廊 | [3, 1, 1, 6]（竖排房名） | drape.png |
| 阿雪的空房 | [4, 1, 2, 2] | wall_gray.png |
| 中庭 | [4, 4, 2, 2] | gravel.png |

右上角写"↑ 廊底　↓ 入口"。门按出口自动画：主廊连四间。

### 各条线要做的

- **场景线**：
  1. 主廊墙边的旧唐伞小积木，要能撑开、合上（伞面分几片，代码转角度，像天秤那样）。
  2. 中庭井口站位。
  3. 空房壁橱（门能拉开）和里面那排湿东西。
  4. 拾遗 3 件（发簪、纸鹤、信）。
  5. 两个拍照点、主廊的 `bossAt`。
  6. 每样东西叠到扫描画面上截图，看搭不搭、有没有浮空。
- **文案线**：
  1. 6 张卡结尾改成疑问。
  2. 阿浅、阿龟、歌山各 2~3 句。
  3. hint、hold 各一句。
  4. act 三句：看伞、往井里看、打开柜子。
  5. find 三张、note 摘记、开场卡。
- **角色线**：往井里看用现成的 gaze_k（低头看），看伞用 scale_look_k，打开柜子用 reach_k。都先用现成的，不顺手再说。不花积分。
- **总指挥**：
  1. act 带一个"会动的东西"（伞撑开、柜门拉开），复用找线索时那套小积木加载。
  2. 井里浮起的影子用墨影和魂光的贴图做。
  3. 本命出在起点那间的特例（第一次进来不出，回来才出）。
  4. 四间房的门札变成回主廊。
  5. 自测。

## 四、要动的代码（总指挥，两个地点通用）

1. **act 扩展**：每个 act 可以写动作名（`anim`）、效果（`fx`：incense 线香 / steps 头顶脚步 + 小黑影 / pinwheel 风车 / peek 井里浮影 / open 打开柜门 / kasa 伞撑开），以及做完那句话。现在只有坟前合掌一种。
2. **宅图**：加 `compass`（右上那行字）。格子表的行数、列数已经能配。
3. **本命出在起点**：大奥加 `bossReturn: true`，意思是要从别的房间回来才出。
4. **配角冒话在扫描房间里**：纸条的位置按配角头顶算，扫描房间是环绕镜头，要试一下会不会被挡。
5. **自测**：每个地点一项"凑齐线索 → 本命现身"，一项"案卷翻得开"。

大致顺序：你在坂井家走完第二圈 → 你定下面几条 → 文案线、场景线同时开工（两个地点可以一起，也可以先做万屋）→ 我接代码 → 每个地点你走一圈 → 三个地点一起上线。不花积分。

## 六、定下来的（11-05）

你回"按方案来"：五条都照方案——万屋第一次随机出青座敷；大奥本命在主廊、从房间回来才出；万屋放小地藏（另加纸风车一起转）；大奥壁橱湿东西用；两处一起开工（场景线先做万屋）。

代码（总指挥，已接，三个地点通用）：
- `acts` 每项：`{ id, pos, face, r, anim, fx, at, props }`。`fx` 可以是一个或几个：incense / steps / pinwheel / peek / open / kasa；`props` 里每个小积木 `{ kit, pos, y, yaw, move, dist, open, show }`，move 有 kasa（XZ 从 0.2 撑到 open 再收回）、slide（沿自身 +X 拉开 dist）、spin（绕自身 Z 转），`show: "after"` 做完才露出来。
- 宅图 `plan.compass` 写右上那行字。
- `case.bossReturn`：刚进地点那一下不出、也不浮 pre；从别的房间回来才出。
- 形真理是在本命那间里凑齐的（万屋常见：最后一样是志乃的话），提示完就在这间现身，不用出去再进来。
- 齐了浮的那句可以写 `ready.<地点>`（大奥：回主廊）。
- 自测：每处 act 站上去按 E 跑一遍效果再记线索；提示三档改成直接拨计时（真跑 150 秒，大奥扫描房间会把 GPU 跑崩）。

逐张截图以后又补的（11-05，图在 `assets/processed/shots/游30_*.jpg`）：
- act 可以写 `cam: { pos, look }`，做的那几秒临时换机位（阿雪空房那台固定机位悬在壁橱正上方，只拍得到边角）。跟随镜头的区块，做 act 时镜头自己慢慢转到药郎身后。
- E 的顺序：観已经看过、旁边又有 act / 拾遗 / 配角时，E 先给那样（空房壁橱挨着観，原来按 E 永远在开说明卡）。做 act 时提示条收着。
- 光点、墨影不进描边（原来被描成一个个小方框）。头顶落灰、滴水的小点去掉了，太小，描不描边都像噪点。
- 小黑影放大、调深，从药郎头后面偏开往一侧跑（原来正好被他的头挡住）。场景线把 at 挪近到 3.5~4 米。
- 井里浮影从水面一路浮到井沿上面（镜头比井沿低，只在水面会被挡）。
- 配角冒话：转到画面外先藏着，转回来还在，4 秒到了才收（原来扫描房间的环绕镜头一转开，纸条就收了，这次进房再也不冒）。
- 宅图：阿雪空房的贴图 wall_gray 像电视雪花，换成 tatami。
