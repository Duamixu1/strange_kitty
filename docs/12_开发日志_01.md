## 一句话

看了一支预告片，用 Tripo、World Labs 和 Claude Code，五天做出一个能从推门玩到结尾的怪化猫同人小游戏。

## 拍前提纲

平时即兴讲的话，看这几条就够了：

- 开头放药郎样片，说这是五天做出来的，在一个能玩的游戏里
- 定画风：先把预告片拆成几条规则；拆完发现难点是画面处理不是模型，所以直接做网页，一个链接就能玩
- 顺序：先做最可能失败的那一步，画风能进 3D 再批量出素材
- 药郎：Tripo 出模型；横斩时大袖被扯成一张膜，拆层加骨链解决
- 房间：World Labs 一张 360 全景图生成能走进去的房间，试了三种喂法
- 玩法：原作"形、真、理"做成天秤配对，故事原创
- 怎么用 AI：开好几个对话分工，一个当总指挥，我负责判断
- 结尾：同人、免费、不卖；下期做配角和中庭

**正文：**

前几天看了怪化猫剧场版《唐伞》的预告片，太喜欢它的画面了，就想给药郎做个小游戏。

五天下来，现在能从推门一路玩到结尾卡。记一下是怎么做的：

· 定画风：没急着动手，先把预告片拆成几条规则：和纸底、平涂、深褐色描边、贴在屏幕上的纹样。拆完发现难的是画面处理，不是模型，所以直接做网页版，一个链接就能玩
· 药郎：三视图喂给 Tripo 出模型、自动绑骨，动作一个姿势一个姿势调。横斩的时候大袖和下摆被两条腿扯成一张膜，后来把衣服拆成几层挂上骨链，现在走路袖子和头发都会晃
· 房间：World Labs 能拿一张图生成一个走得进去的 3D 房间。单张图、四张图、360 全景图三种喂法都试了，全景图最好，每个方向都按我的图来
· 玩法：沿用原作"形、真、理"的规矩，做成天秤配对。故事是原创的，物怪是一只手鞠
· 代码基本是 Claude Code 写的。我开了好几个对话分工，一个当总指挥，我主要做判断：先做哪一步、像不像、积分值不值得花

同人二创，免费，和官方没有关系。画面里的模型和场景都是自己生成的，没用原片素材。

下一期做阿浅、阿龟、歌山和中庭。
