# 药贩子动作清单与制作路线

> 写于 2026-10-23。前提沿用 `04_玩法方案.md` 的原则一"看，不打"：没有实时战斗，拔剑是高潮过场。
> 所以这里的"打斗"不是砍怪，而是**退魔仪式的几拍姿态**，做成可以在游戏里实时播的动作，也可以当 Blender 过场的分镜。

## 一、游戏到底需要哪些动作

按 `05_证物与机位.md` 的分区过一遍，每个区玩家能做的事反推角色要有的动作。

| 区 | 玩家在做什么 | 需要的动作 | 来源 |
|---|---|---|---|
| Z0 门口 | 从画面下方走入，按键推门 | 走、停步待机 | Tripo 预设 `walk` `idle` |
| Z1 走廊 | 来回走、往回走时面对镜头 | 走、转身、待机 | `walk` `turn` `idle` |
| Z1 拾 E1 彩线 | 走到线头旁按键 | **抬手取物**：药贩子不弯腰，证物自己浮起来飞进天秤界面 | `cast_a_spell`（抬手）+ 道具飘浮脚本 |
| Z1a 看壁画 | 切特写看壁画 | 抬头看 | `look_around` |
| Z2 / Z2a 对话 | 走到 NPC 面前按键 | 面向 NPC 待机、点头 | `idle` `agree` |
| Z3 中庭捞 E5 | 井边按键 | 同"抬手取物"（井里的手鞠浮出水面） | `cast_a_spell` |
| Z5 天秤配对 | 特写天秤 | 不需要角色 | 无 |
| 天秤响 | 走廊里天秤颤动 | 停步，低头看腰间天秤 | 自定义 `scale_look`（短，2 秒） |
| Z6 拔剑 | 看 | **退魔三拍**：抽剑、横斩、收剑 + 妖化 | `slash` 打底 + 自定义 |
| Z7 结尾 | 看 | 转身离开 | `turn` `walk` |
| 常驻 | 站着不动超过 8 秒 | 第二待机：抱臂 | `fold_arms` 或 `standing_relax` |

**取物不弯腰**是刻意的设计：原作里药贩子几乎不做大动作，东西都是自己动。顺带躲掉蹲下时下摆和袖子最容易穿模的姿势。

## 二、退魔三拍（"打斗"的做法）

实时播或 Blender 渲都按这三拍分镜：

| 拍 | 时长 | 动作 | 镜头（参考帧） | 效果 |
|---|---|---|---|---|
| 1 抽剑 | 1.5 秒 | 右手搭剑柄，剑柄的脸睁眼，慢抽出三分之一 | 70s 持剑手特写 | 和纸纹变粗，色板瞬间只剩红、藏青、纸白 |
| 2 妖化 | 1 秒 | 头发散开成火焰形，瞳孔缩小，露齿 | 79s 妖化脸 | 已做（10-28）：形态键 `awaken_hair` / `awaken_eyes` / `awaken_mouth`，头发 2.75→3.17 秒散开、7.92→9.17 秒落回，表情 3.08→8.21 秒；描边变红归游戏台 |
| 3 横斩 | 1 秒 | 一步上前，横向一刀，定格 | 29s 眼睛 → 全身 | 画面定格 0.5 秒，纹样爆开（屏幕空间纹样 shader 放大） |
| 收 | 2 秒 | 收剑入鞘，头发落回，天秤静止 | 93s 脸和手 | 色板恢复 |

第 3 拍用 Tripo 预设 `slash` 打底，1、2、收三拍预设里没有，要自定义（见第四节）。
默认仍按 `03_推进路线.md` 的决定用 Blender 渲视频；实时版只在绑骨质量够好时再做，两条路分镜相同。

## 三、动作参数

- 走速 1.0 米/秒，原作慢走；`animate_in_place=true`，位移交给角色控制器。
- 动作之间 0.25 秒交叉淡入；一次性动作（取物、点头、看天秤）播完回待机。
- 走→停：先放 `turn` 的前半截做停步，不另做停步动画。
- 转身：角度小于 60° 直接插值朝向，不播动作；大于 60° 播 `turn`。
- 每个动作单独一个只含动画的小 GLB（`export_with_geometry=false`），运行时套到同一副骨架上，模型文件只装一份网格。

## 四、制作路线

### 路线 A：先用 v1 试可行性（今天就能做，花积分）

v1 的问题（剑和手连体、头发连在躯干上）对"看绑骨和预设动作质量"没影响，正好拿来当试验品。

1. `import_model`：把 `assets/tripo_raw/kusuriuri_v1.glb`（64 MB，上限 150 MB）传回 Tripo，拿到 task id。
2. `rig-check` → `rig`：rig_type `biped`。绑骨模型版本选 **v1.0**，因为 101 个预设动作只有 v1.0 支持（v2.5 只有 11 个，没有 `bow` `look_around` `fold_arms` `agree` `cast_a_spell`）。
3. `retarget`：一次最多 5 个动作，先要 `idle` `walk` `turn` `look_around` `slash`，第二批 `cast_a_spell` `agree` `fold_arms` `standing_relax` `wait`。
4. Blender 里减面（沿用 `tools/blender_lite.py`，要加"保留骨骼和权重"），导出带骨架的 Draco GLB。
5. `web/character.html` 加 AnimationMixer 和按键切动作，在平涂加描边下看：袖子和下摆穿模多严重、剑随手走像不像样、头发是否跟着躯干僵硬地动。

看到的结果决定路线 B 要在 Blender 里花多少功夫。

### 路线 B：正式角色（v2，待办第 5、6、7 项）

1. 重出 A 字姿势、不拿剑、不背箱的三视图，拆正/侧/背三张走多视图生成。
2. Tripo 绑骨（v1.0，biped）+ 同一批预设动作。
3. Blender：拆衣服层，删被盖住的身体，下摆、大袖、长发、帽带挂物理骨链，手和腰加空节点挂剑和药箱。
4. 自定义动作在 Blender 里 K 帧：`scale_look`（低头看天秤）、退魔三拍、妖化形态键。只有这几个，手 K 可以接受；想省事就从 Mixamo 找"sword draw"类动作重定向到 Tripo 骨架。
5. 固定动作烘焙布料，导出。

## 五、Three.js 侧要加的东西

- `web/src/game/anim.js`：AnimationMixer 封装，`play(name, {once})`，交叉淡入，一次性动作结束回 `idle`。
- 角色控制器：按键 → 目标朝向和速度 → 选 `walk`/`idle`/`turn`，位移自己算。
- `character.html` 加按键 5 到 9 预览各动作，用来截图检查穿模。

## 六、手 K 姿势库怎么用（2026-10-23 起）

Tripo 预设只拿来验证骨骼能动，正式动作全部从姿势库出：

1. 姿势写在 `tools/poses/kusuriuri.json`（v2 用 `kusuriuri_v2.json`）。角度在角色坐标系里：pitch 绕左右轴，朝上的骨头（脊柱、头）正值 = 往前低，朝下的骨头（手臂、腿）正值 = 往后摆、负值 = 往前抬（2026-10-27 实测纠正，之前写成"正 = 往前"）；yaw 绕上下轴（正 = 往角色左边转），roll 绕前后轴（正 = 远端往角色左边倒）。`base` 继承另一个姿势。
2. 动作 = 姿势 + 帧号的列表，同一姿势连着两个帧号就是停顿；姿势之间默认缓入缓出。
3. 跑 `blender_pose_anim.py --render 目录` 先看每个姿势的正面和侧面图，对了再加 `--out` 导出 GLB。
4. 查看器里按 K 开一拍二（12 帧/秒定帧），这是运行时做的，GLB 里存的是平滑曲线。
5. 换模型只改 JSON 顶层的 `bind_fix`：它先把新模型的绑定姿势扳成 v1 的基准，再叠姿势库。v2（A 字姿势）的 bind_fix 是 L_Upperarm roll -38、R_Upperarm roll 38、R_Forearm pitch 75；`kusuriuri_v2.json` 就是 v1 的 JSON 加这三行、去掉所有 R_Hand（那是转剑用的）。

已有姿势：stand、breathe、glance、walk_contact_L/R、walk_pass_L/R、scale_look(_in)、reach(_in)、nod、draw_ready、awaken、slash_wind、slash、recover。
已有动作：idle_k、walk_k、scale_look_k（3.4 秒）、reach_k（3.1 秒）、nod_k（0.9 秒）、exorcise_k（10.4 秒，第二节的三拍加一个蓄力和收剑）。
还缺：妖化时头发散开、描边变红、定格时纹样爆开，这三个不是骨骼动作，分别归 Blender 形态键、着色器、后期。

## 七、道具和挂点（2026-10-27）

- 挂点在姿势 JSON 的 `sockets` 里定义，`blender_pose_anim.py` 生成空节点挂在骨头上，随 GLB 导出。palm 型放在掌心，握柄方向 = 垂直手骨、最接近角色正前方；back / front 型贴在背后 / 腹前表面（用百分位数，不被翘起的发梢拉远）。
- 道具 GLB 的原点和朝向在 `blender_props.py` 里对好挂点：剑刀身沿 +Z、原点在握柄中心；药箱贴背面在原点；天秤贴腹面在原点。查看器原样挂上，不再调。
- 剑的指向靠姿势里的 `aim`：其他骨头摆完后，先绕前臂自转、再弯手腕，把剑身转到目标方向，脚本会打印手腕弯了多少度，超过 60° 就改手臂。
- 检查图：`blender_pose_anim.py --props assets/processed/props --render 目录`，道具只在 `props.*.poses` 列出的姿势里出现。

## 八、手指（2026-10-28）

- 骨架里每只手多了四指两节 `{L,R}_Fingers_0`（指根到中节）、`{L,R}_Fingers_1`（中节到指尖），四指一体，拇指留在手骨上。
- 姿势里用 `"R_Fingers_0": {"local": [75, 0, 0]}` 弯：局部 X 是指根连线，正值往掌心收，负值往手背折（别用）。
- 现在的设定：站姿（所有姿势都继承它）两手 15° 放松；抽剑、妖化、蓄力、横斩、收剑右手 75° / 80° 握拳。

## 九、妖化形态（2026-10-28）

- 头发：`tools/blender_awaken.py` 给头部周围的浅色顶点和分层出来的长发网格做位移形态键 `awaken_hair`：头部周围往外蓬，背后长发往两侧和上方飘，往后的分量压到三成（背上有药箱）。形态键只能推动现有网格，所以更像"蓬起来"，分股的火舌不明显；要更像原作得做一套单独的散发模型。
- 表情：Tripo 的眼睛和嘴画在贴图上，而且脸在贴图里被切成很多碎块，形态键改不了。做法是正面渲一张脸（`--stage render`），`tools/awaken_face.py` 在平面图上把瞳孔缩成竖着的小点、虹膜提亮、嘴改成露齿狞笑，再复制眼和嘴附近的脸皮面片做贴片、按同一台相机投影出新 UV（`--stage build`）。贴片平时在脸皮后面 1.2 毫米，形态键打开时到脸皮前面 1.5 毫米，一帧切换。
- 时间轴写在 `tools/poses/kusuriuri_v2.json` 的 `morphs` 里，`blender_pose_anim.py` 把形态键关键帧放进和骨骼动作同名的 NLA 轨道，导出时合成一个动画。

## 十、补的三个动作（2026-10-28）

| 动作 | 用在哪 | 长度 | 做法 |
|---|---|---|---|
| `look_up_k` | Z1a 看壁画 | 3.4 秒 | 头 -6°、脖子 -3°、上身 -1°（朝上的骨头负值 = 往后仰），合计仰约 10°，停 1.75 秒。10-28 从 28° 收小：壁画挪到 1.6 米，和眼睛差不多高 |
| `idle2_k` | 站着超过 8 秒的第二待机 | 10 秒 | 抱臂：上臂往前 30°、往里 20°，前臂横到胸前交叉，带呼吸起伏；大袖靠弹簧骨垂下来 |
| `turn_k` | 转角大于 60° 时 | 1 秒 | 原地左右各倒一下脚；转体由游戏台转模型完成，动作里不带转体，两边不打架 |

第一节表里的需求现在都有对应动作了；`走→停` 仍按第三节的做法用交叉淡入，不单独做。
