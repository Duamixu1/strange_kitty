# 物怪出没：游览版加一点交互（方案，待拍板）

> 11-03 用户说："想让药郎能有更多一些的动作，把目前的游览增加一些交互性。可能会随机出现一些物怪，然后药郎需要进行进攻（这里可以多设计一些姿势）。理解之后开始规划思路和方案，确定之后再改。"
> 11-03 已拍板（见第七节）：三个键、按原作建模三只物怪（确认花约 250~300 积分）、默认开随机出、首次完整退魔之后短版。

## 一、思路

游览版的底子是"随便走、随便看、拍照"，不想把它改成打怪游戏。所以物怪出没做成**偶尔来一段的小插曲**：
- 没有血条，不会输。打不过、不想打，物怪自己会退走。
- 一次 20~40 秒。打完药郎收剑，接着逛。
- 套原作的规矩：**形、真、理**三样齐了才能拔退魔剑。

| 原作 | 游览版里 |
|---|---|
| 天秤指向物怪 | 物怪快出来时，药郎腰上的天秤先抖，铃铛响，屋里暗一点，墙角渗出墨色 |
| 符咒（札）封住物怪 | 主要的进攻动作：投札。每钉中一张，物怪被钉住一下，屏幕上浮出一个字和一句话：**形**（它是什么）、**真**（发生了什么）、**理**（它为什么不肯走） |
| 形真理齐了才能拔剑 | 三张札都钉中，剑鞘"咔"地一响，拔剑键亮起来 |
| 退魔、物怪消散 | 拔剑：第一次播完整的退魔三拍（10 秒，带运镜）；以后播 3 秒的短版。物怪化成墨散掉，掉一张"执念物"卡，收进图鉴 |

## 二、一次遭遇怎么走

1. **预兆（3 秒）**：天秤抖、铃铛、屋里暗一点。药郎自己停下来，按住帽檐看一眼（新动作）。玩家这时候走开，就不出现。
2. **现身**：物怪在药郎前方 3~4 米从墨里浮出来。镜头稍微拉开，让人和物怪都在画面里。
3. **缠斗（十几秒）**：
   - 物怪绕着药郎飘，时不时**蓄力**（身上发光、抖一下，约 0.8 秒），然后扑过来。
   - 玩家按**闪**，药郎往后撤、往旁边闪（几种随机）。没闪开，药郎用大袖一挡，退两步（没有伤害，只是动作和镜头一震）。
   - 玩家按**札**，药郎投札（几种随机：单手甩、回身甩、双手撒一扇）。物怪扑空、刚落地那一下最容易钉中，飘着的时候它会躲。
   - 钉中一张，浮出一个字（形 / 真 / 理）。
4. **退魔**：三张都钉中，物怪被札阵围住不动，按**拔剑**。
5. **消散**：物怪化墨散掉，掉一张"执念物"卡（复用现有的说明卡：图、名字、三句话），收进图鉴。
6. **退走**：60 秒没打完，或者玩家跑远，物怪沉回墨里，下次再来。

**按键**：
- 电脑：J 投札、空格闪避、X 拔剑（拔剑现在就是 X）。
- 手机：右下角已经有按键区（游24、游25），遭遇时多出"札""闪"两个钮，打完收起来。

**出现规则**：
- 只在地方够大、镜头转得开的区块出现（地点文件里标几个出生点，场景线填）。
- 同一时间最多一只。打完或者退走以后冷却 2~3 分钟。
- 菜单里能关掉"物怪出没"。

## 三、药郎的新动作（角色线，不花积分）

做法和现在的走路、退魔一样，都用姿势库生成。有一个技术点：
- **上半身单独一层**：投札、挡这些动作只带上半身的轨道，走路时腿照走，上半身叠着播，不用站定。
- 现在播动作是整身切换，这一层要在 `player.js` 里加。

| 动作 | 时长 | 用在哪 | 层 |
|---|---|---|---|
| 察觉 `sense_k`：停下、按帽檐、侧头 | 1.5 秒 | 预兆 | 全身 |
| 投札·单手甩 `ofuda_flick_k` | 0.6 秒 | 投札（随机 1） | 上半身 |
| 投札·回身甩 `ofuda_spin_k`：转半身，大袖甩开 | 0.9 秒 | 投札（随机 2） | 全身 |
| 投札·撒一扇 `ofuda_fan_k`：两手从胸前往外推出一排札 | 1.0 秒 | 投札（随机 3）；第三张必出这个 | 全身 |
| 结印 `seal_k`：两指立在唇前，札阵收紧 | 1.2 秒 | 三张钉齐 | 全身 |
| 后撤 `dodge_back_k`：往后滑一步，衣摆往前飘 | 0.5 秒 | 闪避（随机 1） | 全身 |
| 侧闪 `dodge_side_L_k` / `R_k` | 0.5 秒 | 闪避（随机 2、3） | 全身 |
| 袖挡 `guard_k`：大袖挡在身前，退两步 | 0.8 秒 | 没闪开 | 全身 |
| 退魔短版 `exorcise_short_k`：抽剑、妖化、横斩、收剑压到 3 秒 | 3 秒 | 第二次以后的退魔 | 全身 |
| 收势 `settle_k`：低头、整一下袖子 | 1.2 秒 | 打完 | 全身 |

后续可以再加：突刺、纵斩、回身斩，妖化状态下随机换着用；蹲下把天秤放在地上（原作招牌动作），给预兆用。

每个动作都按这次退魔的标准验收：
- 逐帧烘焙，身体先动、手后到，带余摆。
- 量剑和札离袖子、身体多远，下摆不拖地，脚不滑。
- 修前修后对比图。

## 四、物怪长什么样

| 方案 | 做法 | 花费 | 效果 |
|---|---|---|---|
| A. 墨影小物怪（推荐先做） | 程序生成：一团会变形的墨色剪影，套一张能面或纸面具，中间一只红眼；身后拖几条墨线。扑过来时拉长，被钉中时缩一下、冒墨点，消散时化成墨滴散掉 | 0 | 和画风搭（平涂、墨线、和纸），没有穿模烦恼。三个地点换面具和颜色就是三种 |
| B. 复用探案版的手鞠物怪 | `temari.glb` 和 `temari.js` 现成，有长线、收线的动画 | 0 | 大奥篇专属；其他地点不合适 |
| C. 按原作每篇做一只 | 坂井家化猫（黑猫剪影）、万屋座敷童子、大奥唐伞或火鼠。Tripo 出模型 + 绑骨 | 每只约 100~150 积分 | 最像原作，但要配原作参考图，还要做物怪自己的动作 |

建议先用 A 做通整套玩法，B 当大奥的彩蛋，C 等玩法定下来、确定好玩了再说。

**特效**（都是程序生成，不花积分）：
- 札：纸条贴图加红印。飞出去有拖尾，钉中时啪地贴住、抖一下。
- 札阵：几张札绕着物怪转圈，连成线。
- 钉中：一点墨溅，加一个字（形 / 真 / 理）浮起来。
- 消散：墨滴往上飘散，屏幕一闪，接金描边退掉。

## 六、要你拍板的事

1. **操作多少**：
   - 轻操作：投札、闪避、拔剑三个键。
   - 更简单：只按一个键，药郎自动打完，主要看动作和运镜。
   - 更像动作游戏：有体力、物怪会打掉札。
2. **物怪外观**：先做免费的墨影（A），还是一开始就花积分按原作做（C）。
3. **出现频率**：默认开着、随机出；还是默认关，菜单里打开；还是只在固定的几个地方、走过去才触发。
4. **第一次退魔**：每次都播完整的 10 秒，还是第一次完整、之后 3 秒短版。

## 八、总指挥这一半做完了（11-04）

代码：
- `web/src/tour/encounter.js`：遭遇状态机。
- `web/src/tour/mononoke_fx.js`：札、札阵、墨点、字的特效；加载原作物怪；占位用的墨影。
- `player.js`：上半身层，`playUpper`。
- `tour.js`：接线。
- `audio.js`：加了 13 个程序合成的音效（预兆、现身、蓄力、扑、投札、钉中、字、袖挡、闪、结印、消散、退走）。

**流程**（全按帧推，不靠定时器，自测里一帧一帧推也对得上）：
1. 预兆 3 秒：铃两下、屋里往紫灰压、屋角渗墨、天秤抖，药郎停下察觉（`sense_k`）。这时走开 2.5 米以上，这次就不出。
2. 现身 1.2 秒：物怪在镜头前方 2.5~7 米浮上来（`appear_k`），镜头拉开两成。
3. 缠斗：
   - 物怪绕着药郎飘，半径 2.8 米，只在现身那一刻镜头前方左右各 60° 里来回。
   - 每 2~4 秒蓄力 0.8 秒（发红、抖）。蓄力一开始就瞄准药郎当时的位置，然后扑过去，停在他跟前 0.6 米。
   - 蓄力时按闪就扑空。没闪开药郎袖挡（`guard_k`），退 0.35 米，镜头一震，没有伤害。
   - 扑空落地有 1.5 秒破绽，这时投札一定中；蓄力时投中一半；飘着的时候只中两成，擦过去它会往另一边一闪。
   - 跟随镜头会慢慢转到"物怪 → 药郎"这条线后面偏 35°，像过肩镜头那样。玩家拖镜头时不转；固定机位、泼溅轨道也不转。
4. 投札：
   - 单手甩（只带上半身，边走边投）、回身甩随机。第三张固定撒一扇（5 张，中间那张定中不中）。
   - 出手时间按 17 第十五节：0.33 / 0.5 / 0.5 秒。
   - 钉中一张，札贴在物怪身上，溅墨，头上浮出 形 / 真 / 理，下面一句话。
5. 三张齐：札阵（8 张札连红线绕着转、收紧），药郎结印（`seal_k`），拔剑钮发亮。
   - 没齐时按 X，提示"形、真、理还差几样，剑拔不出来"。
   - 没有物怪时 X 照旧随便拔。
6. 退魔：第一次完整 `exorcise_k`（带运镜）。之后 `exorcise_short_k` 3 秒（不带运镜，节奏点按 17 配了金描边和音效）。
   - 横斩那一下物怪化墨往上飘散、闪一下。
   - 播完药郎收势（`settle_k`），掉一张执念物卡，记进图鉴（本机 localStorage，"图鉴 n / 3"）。
7. 60 秒没打完，或者药郎跑出 9 米，物怪沉回墨里。冷却 2~3 分钟；第一次出在进地点后 40~80 秒；换区块直接收掉。

**物怪模型**：
- 进地点、加载提示淡出以后，在后台下这个地点那一只（0.4~0.8 MB），不拖慢首次加载。
- 还没下完就先用墨影顶上。
- 缠斗时药郎站着是戒备 `ready_k`。

**按键**：
- 电脑：J 投札、空格闪避、X 拔剑。
- 手机：遭遇时朱红大圆变成「札」，姿势的位置变成「闪」，拍照挪到右上角，形真理齐了「拔剑」发金光。
- 右上角「音」下面的「怪」开关物怪出没，记在本机；关掉时正在打的那只直接收掉。

**出生点**：
- 区块里写 `mononoke: [[x, z], ...]`，场景线标。
- 没标的区块不出物怪。
- 开发时 `?mononoke=any` 不看出生点，在镜头前方自己找空地。

**文字**：`text.json` 的 `mononoke.<地点>`：`{ name, katachi, makoto, kotowari, itemTitle, itemBody }`，文案线写。没写时用占位：形只写物怪名，真、理不浮句子，卡上写"说明待文案线写"。

**自测**：`tools/tour_selftest.sh` 每个地点多 5 项，用的是原作模型：
- 第一次：钉齐三张，完整退魔、消散、掉卡。
- 第二次：短版。
- 第三次：不理它，60 秒后退走。

三个地点各 23 项全过。流程图：`shots/物怪出没_遭遇流程_第一版.jpg`。

**11-04 追加：跳和瞬移**（你本机试玩后说"药郎的动作有点单一，能跳跃和瞬移躲避吗"；定了只在遭遇里用，三种都保留）：
- 空格侧闪不变；K 跳：原地跳起 0.7 米、往后飘 0.3 米，离地到落地之间不会被扑中（物怪从脚下扑过去），冷却 0.9 秒；镜头不跟着上下。
- L 瞬移：化成一把札纸散掉（带墨烟），2.4 米外现身（窄的地方 2 / 1.6 米）。按着方向键就往那边，不按就往物怪侧面；一路上都要站得住（不穿墙），优先挑在画面里的点；现身那一帧镜头直接切过去。冷却 3 秒，冷却中再按会提示还差几秒。
- 手机遭遇时多两个钮：「跳」在「闪」右边，「瞬」在拔剑上面，冷却中变淡。
- 动作：角色线 11-04 交了 `jump_k`（0.75 秒，0.17 离地、0.54 落地）和 `blink_k`（0.5 秒，0.15 消失、0.25 现身），时间点见 17 第十七节，`encounter.js` 的 JUMP / BLINK 已换上；模型里没有这两段时才用占位（ready 抬起 / `dodge_back_k`）。
- 自测第 2 次遭遇改成蓄力时按 K 跳、开打 1.5 秒按 L 瞬移，三地点都过（大奥走廊也瞬得开 2.4 米）。
