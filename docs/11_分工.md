## 三、协作规则

1. **待办表只有一张**：`docs/02_待办.md`。新加的条目在事项开头写【线名】（如【场景】），做完改状态写日期。改之前先重新读一遍最新版，只改自己那几行，避免几个对话互相覆盖。
2. **游戏台只由总指挥改**：其他线把成果放在自己的文件里（模型、数据、文字），在待办表里写"可以接了"，总指挥负责接进 `game.html` 并验收。这样不会几条线同时改 `game.js` 互相覆盖。
3. **花积分前先说**：Tripo、World Labs 一次几十到一千五百积分，开跑前在对话里说清楚要花多少。
4. **画风一致**：出图一律挂 `assets/concept/00_色板.png` 和相关主参考图，用同一个图片模型；一批出完排成一排检查漂移。
5. **验收看真窗口**：泼溅在后台页面画不出来。截图验收要在可见窗口里做；开发服务器 `npm run dev --prefix /Users/duami/socialmedia/mononoke-game/web`，游戏 `localhost:5173/game.html`，直接进房间加 `?at=maids` / `utayama` / `yuki` / `courtyard`。
