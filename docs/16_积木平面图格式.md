# 积木平面图格式（游览版，场景线）

> 2026-10-29 写。一个区块（一间房、一段廊下、几间连着的房）画成一张文字平面图，`tools/kit_build.py` 按图拼出 GLB 和可走格子。
> 你看片时也可以自己画一张，照下面的字符写，发给场景线就行。

## 一、文件和命令

- 平面图放 `tools/kit_plans/<区块名>.txt`，一个区块一个文件。
- 生成：`/Applications/Blender.app/Contents/MacOS/Blender -b --python tools/kit_build.py -- <区块名>`
  - 不带参数时生成大奥积木走廊（`ooku_corridor_kit.glb`，那段走廊是手写的，不走平面图）
  - `-- all` 把 `tools/kit_plans/` 里的全部生成一遍
- 输出：
  - `assets/processed/kit/<区块名>.glb`：模型，材质名 `kit_<key>`，网页用 `web/src/tour/kit.js` 换成卡通材质
  - `web/src/data/tour/<区块名>_walk.json`：可走格子 + 出生点、观景点、楼梯口、验收机位（格式见第四节）
- 看效果：开发服务器开着时打开 `http://[::1]:5173/kit_view.html?plan=<区块名>`，0 是俯视（红点 = 可走格子），1~9 切平面图里写的 shot 机位，拖动环视；
  拍图 `tools/kit_shots.sh view <区块名>`，存到 `assets/processed/shots/kitview_<区块名>_*.jpg`。

## 二、写法

```
name: zashiki_demo        ← 区块名，和文件名一致
height: 2.7               ← 天花高（米），默认 2.7
ceiling: sao              ← sao 竿缘天井（默认）｜ goten 格天井 ｜ none 不封顶（院子）
shot: 进门 | 3.6,1.5,6.6 | 3.6,1.2,1.0 | 3.2,3.6,3.1    ← 验收机位，可以写多行（见下）
---
#########
#TTT#SSS#
#...F...#
#.1.F.2.#
#...D...#
#SDS#SDS#
#==@====U
#SSSSSSS#
```

- `---` 上面是设置，一行一个 `键: 值`；`#` 开头的行是注释。下面是图。
- **一格 = 半间 = 0.91 米**，一个字符一格。全角字符不要用。
- 坐标：图的左上角是 (0, 0)，往右是 +x，往下是 +z（图的上方是"里"，-z）。第 i 列第 j 行的格子中心在 `((i+0.5)×0.91, (j+0.5)×0.91)`。区块放进地点时由地点 JSON 整体平移、旋转。
- `shot:` 三段用 `|` 隔开：镜头位置 x,y,z ｜ 看向的点 x,y,z ｜ 药郎站位 x,z,朝向（弧度，0 是面向 +z）。单位米。
- 其他设置：`fanlight: on` 门洞 `D` 和玻璃门 `G` 上加半圆彩玻（天花要够高，2.4 米以上）；`seams: across` 廊板缝横过廊下；
  `mat: 角色=材质, …` 换材质，角色有 `wood`（柱、长押、鸭居）、`plaster`（墙的下半截，到长押）、`kokabe`（长押以上，默认同 plaster）、
  `frame`（襖框、床框、屏风框）、`tatami`、`engawa`、`earth`、`toko`、`fusuma`、`shoji`、`dais_side`。材质 key 要在 `web/src/tour/kit.js` 登记过，没登记的显示品红。
  `ceiling:` 写天花贴图的 key：`sao`、`goten`、`goten_teal`，或者 `none`。
  `timber: 1.8` 木料粗细倍数（柱、鸭居、长押一起放大；`o` 独立柱再粗 1.35 倍）；`koshi: 0.95` 土壁最下面加一截腰板（米），材质角色 `koshi`（万屋门厅用 `koshiita` 焦茶竖板条）。
  `facade: wanya` 外景用：在第 0 排那面墙上面加万屋的多层楼正面（二三楼外廊、栏杆、障子窗、出檐、提灯、大屋顶、正门上方的唐破风）；外景记得 `ceiling: none`。
  `surround: machi` 外景四周：地面往外铺到 40 米、第 0 排对面（图的南边外 3 米）一排町家、左右邻家墙后的屋顶、远处一圈墨色屋顶剪影；背对主楼看不会是虚空。
  第二轮布置加的（10-30）：`tatami_border: 0.8` 畳四周黑漆框（米）；`koshi_mat` 见 `koshi`，角色 `koshi` 可换 `plaster_teal`；`dais_items: on` 高台上摆坐垫、肘几、漆盒、烛台；
  `fanlight: big` 门上改成大拱形彩玻（莲花 / 五芒星 / 家纹轮换，`E` 那扇更宽、罩住两旁玻璃门，楼梯口 `U` 上也有）；`counter_sign: on` 柜台正面挂"同"字圆牌；
  `chair_scale: 1.3` 椅子放大；`oct_ceiling: cx,cz,r` 八角藻井（米）；`rug: x0,z0,x1,z1; …` 红地毯（格，可带小数）；`rock_scale: 1.6` 庭石放大；`mural:` 也可以写 `ougi_wall`（扇面画）。`place: trap 0.72,2.0,95; fish 0.62,2.3; …` 按米摆小东西（坂井家厨房，游29）：`种类 x,z[,yaw 度]`，种类有 trap / trap_open（捕鼠夹，不挡路）、fish（梁上垂一串鱼干）、ricebag（两个米俵）、basket（空竹篮）。`doma: 0.36` 土间下沉（坂井家玄关）：`_` 格整片低这么多，墙脚、柱、挨着土间的门扇跟着往下伸；土间和别的地面交界立焦茶上框，正对正门 `E` 放一块沓脱石（kutsunugi，半高），上框其余地方挡住；可走格子带 `floor`。
  `mural_full: on` M 格整面墙一幅画（从地到天花，长押、腰板、墙中间的柱子都让开；大座敷凸间的美人画屏风）；`ceiling_fit: room` 天花整片铺一张图（UV 按所有地面格外框 0..1，群鸡图）。
  **整套换材质（游31，11-06）**：不在平面图里，在地点 JSON 顶层写 `"mat": "ink"`（tour.js 进地点时 `setKitMat(loc.mat)`，kit_view.html 用 `&mat=ink`）。区块平面图照常写自己的 `mat:`，运行时再按 kit.js 的 `INK_MAP` 整套换：木 / 框 / 畳 / 障子 / 襖 / 灰泥 / 廊板 / 天花 / 石 / 土间 / 白砂 / 瓦 / 庭石换成 `*_ink`（tools/kit_textures.py ink_set），其余带贴图的按亮度压成墨—纸白之间的灰，纯色按亮度换灰，深红和珊瑚归成朱红（唯一点色）。
  `kamoi: 2.4` 鸭居高（襖、障子、门洞和玻璃门的高度，默认 1.76），长押跟着抬；`fusuma_span: 5` 一幅襖绘横跨几扇（默认 4，从每一排的第一扇算起）；`mat: byobu=…` 换屏风画，`byobu_h: 2.6` 屏风高（默认 1.75）。

## 三、字符

| 字符 | 是什么 | 能不能走 | 说明 |
|---|---|---|---|
| ` `（空格） | 外面，什么都没有 | 不能 | |
| `.` | 榻榻米 | 能 | 一个房间（连成一片的 `.`）是长方形时，按"柱心"尺寸铺整畳 + 半畳；不是长方形就按格铺半畳 |
| `=` | 廊板（廊下、缘侧） | 能 | 板缝顺着这片廊下的长边 |
| `_` | 土间 | 能 | 玄关、厨房的泥地。暂时和地板同高 |
| `T` | 床之间 | 不能 | 抬高 12 厘米的木台，靠墙那面挂一幅挂轴。挨着榻榻米的那条边在 `T` 格的正中（柱心） |
| `#` | 土壁 | 不能 | 满高的墙 |
| `F` | 襖（关着） | 不能 | 一格一扇。连成一排的襖共用一幅襖绘 |
| `S` | 障子（关着） | 不能 | 一格一扇，下面有腰板 |
| `D` | 拉门门洞（开着） | 能 | 上面有鸭居和小壁，地上有敷居 |
| `U` | 楼梯口（转场门） | 不能，走到门前触发 | 深红框的襖。不做真楼梯：走到门前，地点 JSON 决定转到哪个区块 |
| `o` | 独立的柱子 | 不能 | 大广间里不靠墙的柱子。地面跟周围的格子 |
| `@` | 出生点 | 能 | 地面跟周围的格子，一个区块一个 |
| `1`~`9` | 观景点 | 能 | 地面跟周围的格子。说明卡文字按 `<区块名>.<数字>` 对（文案线的 `text.json`） |
| `K` | 火灯窗 | 不能 | 土壁上开一个钟形格子窗（两面都有），要放在直的墙里 |
| `G` | 彩色玻璃门（关着） | 不能 | 一格一扇，像襖一样成排；`fanlight: on` 时门楣上有半圆彩玻 |
| `/` `\` | 斜墙 | 不能 | `/` 连右上和左下的格子，`\` 连左上和右下；普通墙格会自动接上指向它的斜墙。八角厅这样画（见 `wanya_rouka.txt`） |
| `P` | 高台 | 不能 | 连成一片的 `P` 是一座抬高 32 厘米的台，青磁侧面、地毯台面 |
| `R` | 柜台 | 不能 | 连成一片的 `R` 是一张柜台 |
| `Y` | 屏风 | 不能 | 连成一排的 `Y` 是一架折成之字的金屏风 |
| `h` | 洋式扶手椅 | 不能 | 靠墙的背朝墙；不靠墙的背朝离房间中心远的那边 |
| `M` | 贴画的土壁 | 不能 | 土壁下半截贴一幅画，连成一排的 `M` 共用一幅；画用设置 `mural:`（默认 `mural_L`，大奥左墙美人画） |
| `E` | 出入口（玻璃门样子） | 不能，走到门前触发 | 功能和 `U` 一样（算进 `stairs`），外观是彩色玻璃门；万屋正门用 |
| `,` | 白砂 | 能 | 室内庭、院子的地面（`gravel` 贴图，耙纹） |
| `~` | 水 | 不能 | 水面比地面低 0.22 米，和别的地面交界处自动立一圈石岸 |
| `b` | 拱桥 | 能 | 连成一片的 `b` 是一座红拱桥，顺长边起拱（设置 `bridge_rise:`，默认 0.55 米），两侧有栏杆、两头敞开；画在水上，两头各多画一格岸。可走格子会带 `floor`（桥面高度），药郎贴着走 |
| `r` | 庭石 | 不能 | 地面跟周围 |
| `k` | 黑影人 | 不能 | 墨色剪影，头顶一朵小花（座敷童子的人群；没有参考帧，先做通用的） |
| `H` | 火灯窗障子 | 不能 | 像襖一样成排，一格一扇：山吹底板上一个钟形障子窗、深红框（大座敷左墙） |
| `N` | 第二种襖（关着） | 不能 | 和 `F` 一样，贴图角色是 `fusuma2`，同一间房两面墙可以用不同的襖绘（坂井家大座敷：两侧浪涛、正面家纹） |
| `l` | 吊灯笼 | 能 | 天花下 1.3 米挂一盏红提灯，人可以从下面走过 |
| `t` | 散落的小玩具 | 不能 | 手鞠、陀螺、茶盘，随机两三样 |
| `L` | 石灯笼 | 不能 | 火袋亮着山吹色 |
| `w` | 竹丛 | 不能 | 几根青磁竹竿 + 萌葱竹叶 |
| `s` | 雪地 | 能 | 笛小路家（游31）。设了 `doma:` 时和土间一样低这么多：寝殿造的高廊比雪庭高（`doma: 0.9`）。地板格（廊板、榻榻米）挨着雪地的边自动立高栏（柱、笠木、中贯、地覆）、封檐板，下面缩进去一道墨色挡板 + 短柱；雪地上的庭石、石灯笼、`place:` 的东西跟着往下 |
| `^` | 台阶 | 能 | 连成一片是一段宽台阶，朝着挨地板的那边往上（每级约 0.18 米），两侧侧板 + 斜扶手挡住；可走格子的 `floor` 按位置斜着 |
| `A` | 格子窗 | 不能 | 像襖一样成排，一格一扇，贴图角色 `lattice_win`（笛小路家长廊左墙） |
| `n` | 香几 | 不能 | 黑漆矮几，上面香炉、香盘、香箸（角色 `lacquer`、`censer`、`genji_line`） |
| `m` | 香柜 | 不能 | 三层黑漆厨子棚，每层小香盒 |
| `v` | 几帐 | 不能 | T 字木架垂两幅帘（角色 `kicho`） |

笛小路家（游31）加的设置：
- `zone: i0,j0,i1,j1 | 角色=材质, …`（可以写好几行）：这个格子范围（含两头）里换材质。隔断的襖两面各按它朝的那一格算，所以红色之间那面红、隔壁那面还是墨溅。天花也是角色（`ceiling`，默认等于 `ceiling:` 设置）。
- `hikite: genji` 襖的引手做成源氏香纹（六角底板 + 五根竖条，角色 `genji_plate`、`genji_line`）；`genji_posts: on` 独立柱 `o` 的柱头两面各挂一枚大的。
- `post_h: 2.6` 独立柱的高（出檐下面的廊柱，别顶穿屋檐）；`eaves: x0,x1,墙面z,墙面y,出深,落差`（米，`;` 隔开多段）一段出檐盖住外廊。
- `gate: on` 连成一片的 `E` 做成板葺棟門（两根粗柱、冠木、两坡屋顶，角色 `gate_roof`）；`wall_cap: all` 或行号 土塀压顶小两坡瓦。
- `surround: yuki` 四周雪地铺到 40 米（高度跟雪庭），远处一圈淡墨枯树、屋顶剪影（角色 `far`、`tree`）。
- `dais_h: 0.24` 高台的高；高台台面、侧面、压边的角色是 `dais`、`dais_side`、`dais_trim`。
- `place:` 加了 `pine x,z,高`、`baretree x,z,高`、`mossrock x,z,大小`（半埋的苔石）、`twigs x,z`（雪上枯枝）、`foot` / `foot_r` / `paw` / `paw_r x,z,朝向度`（雪上的小孩脚印、兽爪印，fue_print）。
- `ruin: on`（和 `gate: on` 一起）退魔后的废墟和春天：茅草顶塌半边、门板倒、墙裂、雪地长草、墙外樱花，材质 fue_ruin_* / fue_grass / fue_sakura 平时藏着（kit.js `hide`），`recolorKit(…, "color")` 时出来，原来的门（fue_gate_*）藏起来。`gate: on` 时门洞 `E` 的贴图跨整排（看进去的景）、不画门框。
- `misu: on` 高台朝 +z 那边挂御簾（1.2~2.35 米，挡住坐着的人的脸），角色 `misu`、`misu_cord`；`koubako: act` 时 `m` 格只挡路，香柜换成 act 小积木 act_koubako / act_koubako_drawer。
- 材质整套：笛小路家的平面图都用 `fue_*` 材质（本身是水墨的），每个都有 `fue_*_color`；地点 JSON `"mat": "ink"` 加载，退魔后 `recolorKit(根节点, "color")` 换成彩色（web/src/tour/kit.js）。

### 墙在格子正中

`#` `F` `S` `D` `U` 这几种"墙格"，墙板立在格子的**中线**上（就是柱子的中心线），地板会伸进墙格半格到墙脚。所以：

- **房间按柱心算的尺寸 = 里面的格数 + 1**。6 畳（3.64 × 2.73 米 = 4 × 3 格）画成里面 3 × 2 个 `.`；8 畳（4 × 4 格）画成 3 × 3。
- 两间房之间的隔断只占一排墙格，两边地板各伸进来半格。
- 墙格的走向由相邻的墙格决定（像接水管）：左右有墙格就是横墙，上下有就是竖墙，拐角和丁字口自动接上并立柱。
- 襖、障子、门洞、楼梯口要画在**直的一排**里，不要放在拐角格上（拐角格会被当成土壁）。

### 柱子

自动立：墙的拐角、丁字口、端头；墙的种类变化处（比如土壁接门洞）；长段土壁每隔一间（两格）一根。`o` 是额外的独立柱。

## 四、可走格子 `<区块名>_walk.json`

和 `web/src/data/walkmap.json` 同一个格式（`createCollision(map)` 直接能用），多几个字段：

```json
{
  "name": "zashiki_demo", "cell": 0.1, "x0": 0, "z0": 0, "w": 82, "h": 73, "radius": 0.25,
  "rows": ["0001111…", …],            // rows[j][i] 为 '1' 表示格子中心可站，已经扣掉 0.25 米身体半径
  "size": [8.19, 7.28],               // 整张图的宽（x）、深（z），米
  "height": 2.7,
  "spawn": [3.18, 6.37],              // @ 的格子中心
  "views": { "1": [1.82, 3.18], … },  // 观景点格子中心
  "stairs": [ { "door": [8.19, 6.37], "stand": [7.73, 6.37], "face": [1, 0] } ],   // 楼梯口：门的中心、站哪触发、朝向
  "shots": [ { "name": "进门", "cam": [...], "look": [...], "player": [x, z, yaw] } ]
}
```

没有拱桥的区块不出 `floor` 字段（地面都是平的，y = 0）；有拱桥的出 `floor`（每格厘米，int16 小端 base64，和 `walkmap.json` 一样）。只留和出生点、观景点、楼梯口站位连着的格子（斜墙外侧、家具缝里走不到的小块会去掉）。
