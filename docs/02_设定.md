# 画风 canon 与色板

> 定于 2026-10-23，依据预告片『劇場版モノノ怪 唐傘』特別予告 -表の巻- 逐秒截帧（`assets/concept/ref/`，只放本机，不进游戏）。
> 下面的规则是所有概念图、贴图、着色器的共同依据。生成任何图都要挂 `00_色板.png` 做参考，提示词里自动接 `tools/scenes.json` 的 canon。

## 一句话

浮世绘风格的 2D 赛璐珞动画，整屏蒙一层揉皱的和纸，纯平涂、彩色描边、大面积传统纹样。

## 画面规则

| 要素 | 规则 |
|---|---|
| 纸 | 和纸纹理是屏幕空间的后期叠加，固定不动，所有物体都"透"出纸纹 |
| 着色 | 纯平涂，最多 2 阶（固有色 + 一层阴影色），没有高光、没有真实光照、没有投影 |
| 描边 | 细线，颜色 `#322D48`，外轮廓粗、内部线细 |
| 纹样 | 麻叶、市松、青海波、七宝、纱绫形；铺在衣服、拉门、壁画上；纹样本身也只用色板色 |
| 纹样的投影方式 | **人物用屏幕空间**（纹样贴在屏幕上，人动纹样不动，原作的标志性做法）；**建筑和地面用世界空间三平面投影**（预告片里地面花纹是跟着透视走的）。实现在 `web/src/style/toon.js`，纹样图由 `tools/patterns.py` 生成到 `web/public/textures/patterns/` |
| 镜头 | 一点透视正对走廊，或固定正侧面；像纸戏一层层叠出景深 |
| 画幅 | 2.39:1 宽银幕（上下黑边当作画面的一部分） |

## 人物 canon：药贩子（电影版）

参考帧：29s 眼睛、79s 妖化脸、93s 脸和手、70s 持剑手。

- 身形：高瘦，站姿笔直，动作少而慢。
- 头：深藏青高平顶帽（#9），淡紫白长发（#10）到腰，发梢粉（#11），尖耳。
- 脸：皮肤淡紫白（#10），金色细长眼，蓝色（#7）粗眉条上各一颗红点，眼周红蓝两色花纹带小点，下唇下方一道红竖线，唇紫。
- 手：指甲黑（#9），手指修长。
- 衣：层叠和服，青磁色（#6）衣领，珊瑚红（#2）和赭金（#4）大块，紫（#8）腰带，纹样铺满。
- 随身：背后大药箱（木色 + 金饰），腰间翅膀形的华丽天秤（#6 + #4），手里退魔之剑（剑柄是一张脸）。
- 妖化态（79s）：头发散开成火焰状，露齿，瞳孔缩小；只在拔剑时出现。

## 场景 canon：大奥走廊

参考帧：4s 主廊、76s 尽头、81s 外廊、7s / 74s 成排女中。

- 笔直的一点透视长廊，尽头是一扇红白扇形的亮口。
- 地面：淡绿（#5）底 + 粉金花纹，中间一条珊瑚红（#2）地毯，两侧细绿细红镶边。
- 墙：整面是巨大的浮世绘壁画（脸、和服）以纸白（#1）、红、赭金为主。
- 布幔：紫色（#8）长布从檐下斜挂到地。
- 灯笼：檐下成排红（#3）纸灯笼；地面两侧每隔一段一盏青磁色（#6）菱格行灯，紫色底座。
- 天花：挂满彩色小饰物的绳。
- 外廊（81s）：珊瑚红地面，绿栏杆，粉和赭金的旋涡云天空。
