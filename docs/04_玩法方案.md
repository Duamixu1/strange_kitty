# 玩法方案：怎么玩、有哪几种选择

> 写于 2026-10-23。`03_推进路线.md` 第二节给了一个默认骨架（第三人称、慢走、无战斗）。这里把可选的玩法拉开成四个方向，比较后给推荐，由你拍板。

## 先定四条设计原则

不管选哪个方案，这四条不变，它们决定"像不像怪化猫"：

1. **看，不打。** 药贩子从不主动动手，拔剑是结果不是过程。游戏的动词是走、看、问、称，不是打。
2. **慢而静。** 一局 15 到 20 分钟，节奏像原作：大段安静，然后一瞬间爆开（拔剑）。
3. **形・真・理是结构，不是收集品。** 三者各对应一种玩法动作：形靠**看**（找到它的样子），真靠**问**（人证），理靠**称**（天秤上的执念）。
4. **每一幕有一个"画面点"。** 能截图、能发视频的画面：走廊全景、天秤颤动、妖化拔剑、物怪消散。这是和你的内容发布接上的地方。

## 四个方案

### A 大奥探案（第三人称探索 + 问话）

就是 03 的默认骨架。操控药贩子在走廊、房间、中庭走动，天秤靠近线索会颤动响铃，走到人物面前问话，对话树里藏线索，三者齐了拔剑。

- 像什么：《小王子》那种走路看风景的小游戏，加一层侦探。
- 优点：最贴原作气质；技术路线 03 已经写透；走廊全景那张图直接就是游戏画面。
- 缺点：写作量大（三个 NPC 各一棵对话树）；如果线索只是"走到跟前按 E"，玩起来会闷。
- 3D 工作量：高（角色全链路、碰撞、镜头）。

### B 纸戏推理（固定机位 2.5D + 找矛盾）

不自由走动。每一幕是一张固定构图的"纸戏"画面（走廊、房间、中庭），3D 场景只是背景，人物是贴着描边的立牌。玩法是听证言、在证言里点出矛盾（像《逆转裁判》的"指出矛盾"），每指对一处拼出一个字。

- 像什么：视觉小说 + 逆转裁判。
- 优点：3D 风险最低，几乎没有穿模、碰撞问题；最省积分；画面可以做到最接近原作（固定构图就是原作的构图）。
- 缺点：核心乐趣全靠文本和谜题设计，写作量最大；"3D 游戏"的成分弱，和你 Tripo + Three.js 的技术展示诉求不太搭。
- 3D 工作量：低。

### C 天秤称心（探索 + 证物解谜）

保留 A 的走动，但把"问话拼线索"换成"收集执念物放上天秤"。天秤是核心道具：靠近物怪的痕迹时颤动指路；收集到的证物（一把伞、一封信、一只簪）可以放到天秤两端，**放对一对，天秤平衡，一个字亮起**。形是"物怪留下的痕迹"配"它原来的样子"，真是"人证"配"物证"，理是"执念物"配"被舍弃的东西"。

- 像什么：《锈湖》一类的物品解谜，但在 3D 空间里走。
- 优点：玩法有实感，不靠大段对话；天秤是原作标志物，做成核心机制很顺；解谜比对话更容易做"分享点"（天秤平衡那一下）。
- 缺点：要设计 6 到 8 件证物和配对逻辑，物品都要建模；谜题太简单会无聊，太难会卡人。
- 3D 工作量：中高。

### D 物怪夜巡（轻恐怖潜行）

夜里的大奥，物怪在走廊里游荡，玩家操控阿浅（不是药贩子）躲在拉门后、吹灭行灯、用札封住房门，撑到天亮或找到药贩子。

- 像什么：《零》《Little Nightmares》的轻量版。
- 优点：最"游戏"，紧张感强，视频素材最好剪。
- 缺点：偏离原作气质（原作不靠吓人）；要做物怪 AI、追逐动画、视线判定，技术和工作量都是四个里最高；穿模和碰撞问题最多。
- 3D 工作量：最高。

## 比较

| | A 探案 | B 纸戏 | C 天秤 | D 夜巡 |
|---|---|---|---|---|
| 像原作 | ★★★★ | ★★★★★ | ★★★★ | ★★ |
| 玩起来有意思 | ★★ | ★★★ | ★★★★ | ★★★★ |
| 写作量 | 高 | 最高 | 中 | 低 |
| 3D 风险 | 高 | 低 | 中高 | 最高 |
| 能展示 Tripo + Three.js | ★★★★ | ★★ | ★★★★ | ★★★★★ |
| 一个人几周能做完 | 能 | 能 | 能 | 悬 |

## 推荐：A 的壳子 + C 的核心

走动和镜头照 A（03 已写好技术路线），但把"拼线索"的核心动作换成 C 的天秤配对，对话只保留每个 NPC 两三句，用来给证物提示，不做对话树。理由：

- 写作量从"三棵对话树"降到"八件证物各一句说明 + 三段 NPC 短话"。
- 天秤同时是引导（颤动指路）、UI（显示三个字亮了几个）、核心机制（配对），一个道具三种用途，省东西。
- 两个"画面点"天然就有：天秤平衡亮字、三字齐拔剑。

## 推荐方案的一局流程（约 15 分钟）

| 幕 | 地点 | 动作 | 拼出 | 画面点 |
|---|---|---|---|---|
| 序 | 大奥门口 | 开场卡；药贩子被歌山拦下，天秤忽然响 | | 和纸标题卡 |
| 一 | 走廊 | 跟着天秤的颤动走，找到物怪留下的痕迹（地上的水渍 / 影子），和墙上壁画里"它原来的样子"配对 | **形** | 走廊全景，天秤第一次平衡 |
| 二 | 女中的房间 | 阿浅和阿龟各说两三句，各给一件物证；物证和证言配对 | **真** | 拉门后的房间，证言与物证对上时画面闪一下纹样 |
| 三 | 中庭 / 井 | 在井边找到被舍弃的执念物，和前面拿到的"主人的东西"配对 | **理** | 井口，第三次平衡，三字齐亮 |
| 四 | 走廊尽头 | 妖化拔剑过场（Blender 渲的视频） | | 拔剑 |
| 尾 | 门口 | 物怪消散，结尾卡：显示你拼出的三个字和一句话 | | 结果卡，可保存 |

结尾可以留一个小分支：第三幕的"理"有两件候选执念物，选哪件决定结尾那句话，给二周目一个理由。

## 需要你拍板的

1. 选 A / B / C / D，还是推荐的 A+C。
2. 原创物怪定哪个（行灯 / 镜 / 手鞠），它决定证物是什么。
3. 要不要结尾分支（加一件证物，多一张结尾卡）。
