### 3. 2006 化猫篇（坂井家）

濒临破产的武家坂井家，女儿**真央**出嫁当天，来了一个卖药郎；新娘在玄关死去，家里的人接连被猫形怪物杀死。药郎说要斩它，就要先弄清形、真、理。剧中还有一个曾被坂井家囚禁的女子**珠生**（她和猫的具体关系待核实）[2]。

中村健治说，化猫的视觉参考了浮世绘、原宿时尚、cosplay，也受舞台表演手法的影响 [6]。2023 年的舞台剧改编的就是这一版，他称之为"回到原点" [6]。

### 4. 卖药郎

- 来历不明，自称是人。白皮肤、长发、尖耳，脸上歌舞伎式的隈取妆，和服上是蛾纹 [1]。
- **退魔の剣**：查明物怪的**形（かたち）、真（まこと）、理（ことわり）**，封印才解开。拔剑后变身：皮肤变深、白发、金色纹路；剧场版里头发和纹路改成红色 [1][4]。英文字幕译作 form / truth / reason，也有版本把理译成 regret [3]。
- **天秤**：测物怪离自己多远，造型像投扇興（投扇兴：一种往蝶形靶子扔扇子的游戏）的靶子；还会用符咒设结界 [1]。
- 药箱的具体设定：待核实。
- 2026 年新企划把 TV 版药郎叫「離の剣」（离之剑）、剧场版叫「坤の剣」（坤之剑），新出第三位「乾の剣」（乾之剑），角川文库各出一本小说 [7]。**官方把他们当成不同个体。**

### 5. 剧场版三部曲（全在大奥）

- **唐傘**：新人女中アサ（阿浅）和カメ（阿龟）进大奥，被要求参加一个让人融入集体的"仪式"；御年寄歌山守着秘密。物怪唐傘生于大奥里积压的情念 [4][10]。中村健治说这一部的母题是**水**，也用水的流动表现洗脑一样的压力；大奥这个舞台，是他在白板上画了"药郎站在大奥大厅里"，大家觉得帅就定了 [8]。
- **火鼠**：围绕继承人的争斗，受宠的御中臈フキ（阿蕗）和掌管大奥的大友ボタン（大友牡丹）矛盾加深，接连发生人体自燃 [11]。
- **蛇神**：御台所幸子的男婴夭折，大奥异变不断，大蛇形态的物怪现身，故事回溯到 150 年前大奥成立的时候 [7]。

### 6. 主题（可以当观点用的部分）

- **物怪 = 怪异 + 人的情念、怨念** [1][3]。所以形真理其实是一套理解别人的结构（这是解读，写成你自己的观点，不要说成官方说法）。
- **三部曲的总主题是"合成の誤謬"**（合成谬误）：对每个人最优的选择，加起来反而让整体变糟。中村健治想把夹在集体和个人之间、说不清的那种感觉画成物怪 [8][13]。第一章是新人被要求放下自我、为集体效力。
- **爱**：制作团队讨论后落成一句话：珍惜自己以外的人，并且不求回报 [14]。
- **女性的处境**：从座敷童子的妓楼、2007 化猫的大正职业女性，到大奥，影评认为系列一直在写各个时代女性的困境 [15]。

## 三、四个阶段，每次为什么转

### 1. 前传：霍格沃茨（10-15 ~ 10-20）

- 起因：Sac 的《小王子》。他那条推文里有一句话让你印象很深，大意是在 AI 时代获得影响力，最好的方式是用 AI 做出自己的代表作。
- 💬 "我想和他走一模一样的路线，只是人物背景换成哈利波特"
- 做法：Tripo 先把所有素材一批批生成出来，再进 Unity。
- 结果：**进了引擎才发现和概念图差太多。** 素材已经花了积分，返工很贵。
- 💡 带走的教训："先做最可能失败的那一步"。怪化猫开工第一天就定了：先只做一个药郎，看画风能不能进 3D，能进了再出别的。

### 2. 探案版（10-23 ~ 10-29）

**先拆画风，再动手。** 没有马上做，而是把预告片拆成几条规则：

| 原作画面 | 拆成规则 | 怎么做 |
|---|---|---|
| 整个画面蒙一层和纸 | 纸纹固定在屏幕上，不随镜头动 | 全屏后期叠和纸 |
| 大面积平涂，饱和但不脏 | 只用一张色板（后来 13 色） | 卡通着色 2~3 阶，关真实光照 |
| 描边不是黑线 | 深褐 / 藏青的"彩线" | 后期描边，颜色可调 |
| 衣服上的花纹不跟褶皱走，像贴在屏幕上 | 屏幕空间纹样 | 着色器按屏幕坐标采样麻叶、市松、青海波 |
| 像纸戏、立体书，一层层平面叠出景深 | 远景和拉门画用平面贴图 | 平面在这里不是偷工，是风格 |

拆完的结论：**难的不是模型，是画面处理。** 所以没上 UE，直接做网页，一个链接点开就能玩。

**玩法**：原作的规矩是药郎要弄清物怪的形、真、理才拔得出剑。做成一个天秤，两件对得上的证物放上去，天秤平了就亮一个字。故事原创（女中阿雪带进大奥的手鞠被没收），参考了你喜欢的《锈湖》：空间不大，每样东西都藏着一段故事。天秤兼指南针，离线索越近晃得越厉害。

**为什么推翻**（10-29）：
- 💬 "做游戏的话我没有游戏的经验，我感觉这个游戏和场景内容有一点割裂"
- 💬 "我就想先尽量去还原整个怪化猫的场景……从地图为入口进入它每一个事件发生的地方，然后就可以在里面东跑跑西跑跑"
- 💬 "做都做了，直接推翻掉又很可惜，所以就想先把之前做的先保存"
- 后来在视频 brief 里说得更清楚：**我想要的不是解谜，是逛。**

💡 可讲的角度：推翻不等于浪费。药郎模型、着色器、泼溅流程、碰撞、点击寻路全都带进了游览版；被扔掉的只有玩法和剧情。而且两周后（11-05），"每个地点一个小案子，查出形真理"又回来了，只是这次是"逛的理由"，不是"必须解的谜"。

### 3. 唐风支线（10-23 起，10-29 暂停）

- 💬 "基于怪化猫的浮世绘风格，回归唐朝的类似设计，并沿用聊斋志异或者山海经里的故事"
- 你妈妈看了以后说可以再做一个唐朝或宋朝的角色（口播稿 v3 里讲过）。
- 第一个案子《画壁》，三个字改成状・事・见，主角是记异的书生，铜镜代替天秤，笔代替剑。
- 翻车：书生背了一个跟药郎一模一样的方药箱（💬 "额这个书生怎么背了个药郎的药箱。。"），改成《玄奘负笈图》那种竹笈。
- 10-26 发现两个游戏的文件混在一起，拆开；10-29 存档到 GitHub `Tang_Dynasty`，暂停。

### 4. 游览版（10-29 至今）

**定方向**：不做玩法，药郎从一张绘卷总地图出发，走进原作各篇事件发生的地方，随便走、随便看，碰到観点弹说明卡，可以拍照。

**选地点**：先调研了一遍原作（第一节），三条标准打分：好不好还原、能不能复用同一套日式建筑积木、粉丝认不认得。最后是大奥（已有）→ 万屋（TV 第一集，你选的）→ 坂井家（药郎第一次登场的地方）。

**之后一层层加东西**，每一层都是你试玩以后提的：

| 你试玩后说的 | 加了什么 |

| "药郎走动时的脚很奇怪""可能是因为衣服的衣摆没有动？" | 重做走路，下摆跟腿走 |

## 四、遇到的问题和解决办法

按类别排。"好讲程度"是我判断适不适合拿出来做内容：★★★ 一句话就能让人懂、有画面。

### 1. 画风

| 问题 | 怎么解决 | 好讲程度 |
|---|---|---|
| 怪化猫画风极繁，Tripo 出的贴图是糊的、UV 是碎的，纹样贴不上 | Tripo 只管形状，花纹和颜色全交给自己写的着色器；纹样按屏幕坐标贴，这正好是原作的做法 | ★★★（"花纹贴在屏幕上"本身就是粉丝会注意的细节） |
| 细线纹样离远了就看不见 | 纹样线宽至少 14 像素 / 1024，混合度 0.6 以上 | ★ |
| 黑猫在深色地板上糊成一团 | 先加浅色勾边（你说太生硬），改成从轮廓外透出的暖光晕 | ★★ |
| 色板不够：万屋的深色木头 | 加第 13 色焦茶 #573F33，只用在木构，不用于描边 | ★★ |

### 2. 角色

| 问题 | 怎么解决 | 好讲程度 |
|---|---|---|
| 💬 "我不希望牺牲角色的精致度" | 原则定成"设计不为技术让步"：大袖、长下摆、长发都保留，用分层和骨链去解决，而不是把衣服做简单 | ★★★ |
| 横斩时大袖和下摆被两条腿扯成一张膜 | 把衣服拆成下摆、左右大袖、长发四层，各挂一串骨头（下摆 12 条），自写弹簧骨让它们自己摆 | ★★★（前后对比图很直观） |
| 番头徳次后脑勺长了一张笑脸 | 重新生成两次（第二次连背面图都画成全是头发），Tripo 还是认定他前后都是脸。最后不再花积分，直接把后脑勺涂成头发色、把凸起推平 | ★★★（翻车集 004、006、007） |
| 无面的脸被做成了黑头发 | 另加一张贴脸的面具网格。又因为 Tripo 把原脸做在后脑勺上，动作一度做反了 | ★★★（"无面真的什么都没有了"） |
| 志乃的发梳变成一块竖插在头上的薄木板 | 按连通块找出来删掉 | ★★ |
| Tripo 全身模型脸只有 300 像素，眼睛 18 像素，糊 | 另画一张高清头部三视图，把脸单独投到头上（唐风那边先做的） | ★★ |

### 3. 动作

| 问题 | 怎么解决 | 好讲程度 |
|---|---|---|
| Tripo 自带的动作"很一般，没有很还原" | 不用现成动作，在 Blender 里对着参考帧一个姿势一个姿势摆，做成姿势库 | ★★ |
| 走路时药箱离体、手从袖子中间穿出来 | 重做走路，药箱贴回，走路时手缩进袖子 | ★★★（翻车集 001） |
| 膝盖往后弯 | 骨骼旋转的正负号反了 | ★★ |
| 走路像在蹲着走 | A 字姿势的腿是斜的，伸直后变长，自动校正就去弯膝盖补。改用三维骨长算 | ★ |
| 上半身像插在腿上的木桩 | 加骨盆扭转、脊柱反向扭、头保持稳、手臂滞后摆 | ★★ |
| 冲刺像田径运动员踢正步 | 💬 "不是很优雅，不是很帅"。改成滑行：脚落在胯下、小腿往后折、上身前倾 10°、下巴平 | ★★★（"药郎不该跑得像运动员"） |
| 脚步打滑 | 闭环：生成 → 测脚的地面速度 → 自动修正，三轮收敛 | ★ |
| 拔剑：剑从袖子中间穿过、药箱甩飞、头发被拉成一张布、全身同一帧到位像木偶 | 头发拆成 22 缕；动作逐帧烘焙，身体先动手后到，加余摆和呼吸 | ★★★（翻车集 008、009） |
| 小化猫坐姿：第一版"looks so strange"，第二版像狐獴，第三版扭头像断了脖子 | 你最后选三只都站着，各有个性：歪头、回头舔肩、缩着发抖 | ★★★（三版连着看很好笑） |

### 4. 场景

| 问题 | 怎么解决 | 好讲程度 |
|---|---|---|
| World Labs 给一张正面图，两边的墙是它自己编的 | 试了三种喂法：一张图、四张图、360 全景图。全景图最好，每个方向都按你的图来 | ★★★ |
| 它按透视猜房间大小，走廊被当成 4×9 米的小盒子 | 代码里放大 1.5 倍 | ★★ |
| 长走廊被重建成往远处下沉 13° 的坡，尽头比门口低 2 米 | 离线把泼溅"剪切校平" | ★★ |
| 镜头贴墙一米内全糊，像近视没戴眼镜 | 镜头只在不糊的"安全圈"里动 | ★★★ |
| 泼溅本身没有碰撞，人和道具飘在半空，描边透过墙 | 从点云算出能走的范围；描边读泼溅的深度 | ★★ |
| 泼溅太贵（一间房约 1540 积分）、离墙近就糊、没法随便走 | 游览版改用 Blender 脚本搭"日式建筑积木"：柱子、拉门、榻榻米，用文字平面图描述房间。泼溅只留给大奥 | ★★★（"一张文字平面图变成一栋房子"） |
| 平面图上的镜头放到墙外，渲出来是一扇门的特写 | 镜头必须在房间里面 | ★ |

### 5. 镜头和操作

| 问题 | 怎么解决 | 好讲程度 |
|---|---|---|
| WASD 自由走，镜头转来转去很乱 | 改成鼠标点哪走哪，点人点物自动走过去 | ★★ |
| 走路转向时镜头多次闪烁跳跃，有时看不到人 | 跟随镜头沿可走网格做射线，挡住的东西半透明 | ★★ |
| 手机上点地面不方便 | 左摇杆、右按键；"看"改成视角遥控 | ★★ |

### 6. 加载和发布

| 问题 | 怎么解决 | 好讲程度 |
|---|---|---|
| 朋友打开要等很久 | 泼溅按需加载、贴图压小、并行预载、隔壁区块先下 | ★ |
| 💬 "你先不要说是下载，你就说进度就可以了。下载很奇怪" | 加载提示只写进度 | ★★（产品直觉） |
| 加载提示撤得太早，药郎衣服炸成纸飞机 | 加载完先跑一秒再撤 | ★★★（翻车集 016） |
| 想知道多少人来玩 | 接 GoatCounter | ★ |

### 7. 协作（怎么带一群对话干活）

- 开了好几个对话，一个当总指挥，其他分别管角色、场景、文案、剪辑，各改各的文件，共用一张待办表（`02_待办.md`）。
- 踩过的坑：一个对话把唐风写进了怪化猫文件夹；有对话出现在错的会话里（💬 "你是不是出现错对话里"）；两个对话同时改一个文件。后来规定"谁拥有哪些文件"写进 `11_分工.md`。
- 你的角色：💬（口播稿里）"我主要做判断：先做哪一步，像不像，积分值不值得花"，"这跟我上班做产品其实挺像的"。
- 你问过的问题：什么是 UV、WebGL 是什么、为什么出图要花积分。💡 从完全不懂到能拍板技术路线，这个过程本身就是内容。

> 注意：上面第 7 条和"AI 工具"相关的内容，只适合小红书 / 口播那条线。X / Ins / YouTube 定的是为爱发电的粉丝人设，不提 AI。

## 五、游戏里的细节

### 三个地点

| 地点 | 出自 | 做了什么 | 小巧思 |
|---|---|---|---|
| **坂井家** | 2006《怪～ayakashi～》化猫篇 | 七个区块：挂红底白家纹大幕的门楼、玄关、红色长廊、客间、婚礼大座敷、藏白无垢的密室、露天的厨房 | 嫁女儿的喜事 BGM（阳音阶、三味线加太鼓），一进密室就放慢变暗；屋后有一座摆着新鲜花的小坟 |
| **万屋** | 2007 TV 座敷童子篇 | 雨夜街口外景、彩色玻璃门、长廊和八角厅、室内庭院（碎石、水、拱桥）、二楼长廊和大座敷；美人屏风、雄鸡天井 | 人群画成看不清脸的黑影；屋里听到的是闷着的雨声；脚步声按地面变：榻榻米、木地板、石板、碎石、雨里石板 |
| **大奥** | 2024 剧场版《唐傘》 | 走廊、女中房、歌山房、阿雪的空房、中庭，五块泼溅 | 中庭那口井；进门是闭着的拉门，从里往外看不会露出泼溅的破绽 |

### 物怪和药箱

- 十一只物怪：三只本命（化猫、座敷童子、唐伞），加上黑唐伞、无面、火鼠、海坊主、鵺，以及变体小化猫、白化猫、青座敷。
- 操作：投札（钉中一次浮出一个字：形、真、理）→ 三张都中，剑鞘"咔"一响 → 拔剑。没有血条，不会输。
- 魂走：退魔以后不是直接掉卡，而是升起一团魂光慢慢飘走，屋里亮回来，底下一句余韵。小化猫是先亮起母猫的光，三只小的跟上去。
- 斩与送（11-05）：有怨的拔剑，斩的是从它身上抽出来的那团黑墨；没有怨、只是在等的（小化猫等人喂、白化猫想回家、青座敷想有人来找他玩），**剑不出鞘**，药郎结印、贴札、退一步目送它走。
- 药箱：药郎背的那只箱子就是图鉴，4×3 抽屉，收过的抽屉贴上执念物签条，最后一格放天秤。

### 声音（全部在浏览器里现场合成，没用一段原片音乐）

- 每个地点一套生成规则，每次听都不一样：大奥都节音阶 + 古筝，偏冷；万屋平调子 + 八音盒，在雨声底下；坂井家阳音阶 + 三味线 + 太鼓。
- 换场是两声拍子木加拉门声，原作换场的感觉。

### 别人不容易注意到的小地方

- 天秤会在物怪快出现时先抖，铃响，墙角渗墨。
- 拍照有滤镜（F 切换），还有两个拍照姿势。
- 药郎跑不起来，只会"滑"，这是故意的。

## 六、对故事的理解

💡 下面是从你做的决定里归纳的，你说过的原话标了 💬。**这部分最需要你自己的话**，先看哪些对得上。

1. **形真理是一种理解别人的方法。** 形是它是什么，真是发生了什么，理是为什么。药郎不能只靠力气，要先理解，剑才拔得出来。游戏里你一开始把它做成天秤配对（探案版），后来做成投札（物怪出没），最后又放回到逛里：线索散在房间里，查出来剑才动。三次都在找"理解"该放在哪里。
2. **剑斩的不是妖，是缠在上面的情念。** 这是被你那句 💬 "小猫那么可爱，斩杀它很心疼" 逼出来的。去查原作才发现，原来的画面（一刀下去物怪化墨散掉）跟原作的意思是反的。于是有了"魂走"和"斩与送"：执念断了，它就能走了。
3. **不是每只物怪都该斩。** 有的只是在等、在想。剑自己会判断要不要出鞘。
4. **大奥的井。** 新来的女中进门第一件事，是把最心爱的东西丢进那口井。探案版的手鞠故事也是这个：阿雪带进大奥的、母亲缠的手鞠，在门口被没收了。2006 化猫篇的坂井家也有一口井。💡 两口井可以讲成一条线：进入一个地方，要先放下什么。
5. **坂井家的喜事和屋后的小坟。** 上上下下都在笑，屋后却有一座摆着鲜花的小坟。视频里你用的就是这个反差。
6. **万屋顶层那间从来不给客人住的屋子。** 原作里怀孕的志乃被安排进去，座敷童子是被堕掉的孩子们，想被生下来；知道会伤到志乃的孩子，就甘愿被斩。💡 这跟"斩与送"是一回事：物怪不一定是坏的，它也会放手。
7. **合成谬误。** 中村健治说剧场版三部曲写的是：每个人的选择单独看都没错，加在一起却让整体变糟（第一节第 6 条）。大奥的井就是这个：每个新人丢掉一样东西，大奥就运转下去。💡 可以对照你自己在组织里的感受，但这条要你来说。

## 七、对人生和做事的思考

💡 全部是候选，**请你挑出真有感触的，用自己的话重说一遍**，没感触的删掉。

1. **先做最可能失败的那一步。** 霍格沃茨的教训：素材全做完才发现画风对不上。怪化猫第一天只做一个药郎。（工作里也一样：先验证最大的风险。）
2. **推翻之前先存档。** 💬 "做都做了，直接推翻掉又很可惜"。打标签存好，再放心推翻。被推翻的东西两周后以另一种形式回来了。
3. **承认自己想要的不是原来以为的那个。** 以为想做解谜游戏，其实想要的是"走进去逛逛"。
4. **不为技术牺牲精致。** 💬 "我不希望牺牲角色的精致度"。宁可多做一层骨链，也不把袖子做短。
5. **翻车也是素材。** 💬 "其实这种错位的问题也挺好笑的，可以积累一些用来做整活"。不完美的过程比完美的结果更有人看。
6. **心软改变了设计，也让我更懂原作。** 不忍心斩小猫 → 去查原作剑到底斩什么 → 做出"送"。情绪不是噪音，是线索。
7. **我做的事是判断。** 先做哪一步、像不像、值不值得花。不会写代码也能做出东西，但判断得自己来。
8. **执念。** 物怪是执念变的。💡 做这个游戏本身算不算一种执念？什么时候该"斩"（停下、放下），什么时候该"送"（让它好好结束）？这个可以留给你想。
