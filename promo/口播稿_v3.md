## 通读版

**缘起**　大家好，这次我做了一个《怪化猫》的二创。我特别喜欢这部作品，尤其是它的纹样和配色。正好赶上 Tripo 的共创计划，送了不少积分，我就想试试，能不能用 World Labs、Blender 和 Tripo，搭出一个药郎的世界。

**开头**　最后做成了一个能从头玩到尾的解谜小游戏，今天带你玩一遍。

**推门**　故事放在电影《唐伞》里的大奥，也就是江户时代将军的后宫。推门进去，是这条走廊。场景是用 World Labs 生成的：我画一张全景图给它，它就生成一个能走进去的高斯泼溅空间。泼溅本身没有碰撞，我从点云里算出能走的范围，当作边界。最难的是往里面放东西。人和道具是另外做的模型，一开始会飘在半空，描边还会透过墙露出来。

**规则**　玩法参考了我很喜欢的《锈湖》：空间不大，每样东西都藏着一段故事。规则沿用原作：药郎要弄清物怪的形、真、理，才能拔剑。我把它做成一个天秤，两件对得上的东西放上去，天秤平了，就亮一个字。

**形**　进门左手有一幅画，画里的女孩在踢手鞠；地上有一截彩线。两样一配，形就亮了。天秤还兼着指南针，离线索越近，晃得越厉害，还会响铃；站着不动一会儿，也会出提示。操作改过一次。最早是 WASD 自由走，我自己试玩的时候，镜头转来转去很容易乱，后来改成鼠标点哪走哪。

**真**　右手第一间是女中的房间，阿龟会给你半张家书；再去对面，翻歌山桌上的入宫登记簿，真就亮了。两样一对，故事就清楚了：女中阿雪进大奥时，带着母亲给她缠的手鞠，在门口被没收了。做人物时，我最纠结的是还原度：想让人一眼认出是谁，又不想照着原作描。所以我按自己的色板重新做了设定图，摆成 A 字姿势交给 Tripo；平涂、描边和和纸纹理，是后面用代码套上去的。

**理**　最后是理。井里能捞出那只手鞠。手鞠在江户时代很常见，多是母亲用和服剩下的丝线，一圈圈缠给女儿的。尽头阿雪的空房里，还有一个木线轴，和一封没写完的家信。只能选一样放上天秤，选哪个，决定你看到哪个结局。

**拔剑**　三个字齐了，药郎拔剑。这套动作没有用现成的，是一个姿势一个姿势调出来的。做到横斩时出了问题：他的大袖被两条腿扯成了一张膜。后来把衣服和头发拆成几层，各挂一串骨头，让它们自己摆。脚也出过事，一横斩就折起来，像练了骨头折叠术。

**分工**　代码基本是 Claude Code 写的。我开了好几个对话，一个当总指挥，其他的分别管角色、场景、玩法和文案，各改各的文件，共用一张待办表。我主要做判断：先做哪一步，像不像，积分值不值得花。用下来，Opus 是真的好用。

**感想**　说回电影。《唐伞》的画风和 TV 版差别很大，满屏的纹样和颜色，几乎是极繁主义，我特别喜欢。我妈看了以后说，可以再做一个唐朝或者宋朝的角色。所以下一期，我想从《聊斋志异》里挑几个有意思的人物来做。

**结尾**　现在我在做 TV 版里的万屋。这次场景改用 Blender 积木来搭：泼溅好看，但离墙一近就糊，也没法随便走；积木没那么细，能走的地方却多得多。做完会开源，代码在 GitHub 上。最后，谢谢药郎给我的灵感，希望你们喜欢。
