# 制作过程视频：脚本方案 brief

> 2026-10-31，剪辑与宣发线。先选方向，定了再写逐字稿。
> 四块内容每版都会讲到：**角色、场景、遇到的问题（包括 Claude 自己的）、交互构思**。几版的区别只在怎么串。
> 画面只用我们自己的图和录屏，不放原片和预告片（参考截图只放本机）。

---

## 方案 A：时间线版：「一个游戏，做到一半推翻重来」

**一句话**：从看预告片到发链接给朋友，按时间讲一遍，中间那次推翻是转折点。
**长度**：4~5 分钟，一期讲完。

| 段 | 内容 | 画面 |
|---|---|---|
| 开头 | 打开链接就能玩：药郎在万屋里走，按 X 拔剑 | 网页版实录 |
| 1 定画风 | 先拆预告片的规则，难点是画面处理，所以做网页 | 色板、概念图、着色器开关对比 |
| 2 探案版 | 手鞠案、形真理天秤、两个结局 | 探案版实录 |
| 3 推翻 | 玩下来觉得场景和玩法拼不到一起，干脆不做玩法 | 探案版 vs 游览版同一条走廊 |
| 4 游览版 | 绘卷总地图 → 大奥 / 万屋 / 坂井家 → 观景点、拍照 | 游览版实录 |
| 5 翻车 | 挑 3 个最好笑的 | 翻车集 |
| 结尾 | 同人免费，链接在简介 | 地图长卷 |

**好处**：最完整，第一次看的人也能跟上。**风险**：信息多，容易拖长。

---

## 方案 B：翻车版：「AI 帮我做游戏，翻了多少车」

**一句话**：每一段一个翻车画面，然后讲为什么会这样、怎么修的。四块内容都藏在翻车里。
**长度**：2~3 分钟，节奏快，适合当第一条引流。

挑的车（已有素材）：

| 翻车 | 属于哪块 | 原因一句话 |
|---|---|---|
| 药箱离体，飘在背后半米 | 角色 | 走路动作和道具挂点没对上 |
| 徳次后脑勺一张笑脸，重做三次还是 | 角色 | Tripo 多视图认定他前后都是脸，最后涂掉 |
| 冲刺像正步、上身像木桩 | 角色 | 腿的角度是手调的，后来改成程序算 |
| 墙上的灯笼倒着"站"在地上 | 场景（Claude 的错） | 贴图全部上下颠倒，glTF 的坐标约定没注意 |
| 一平视整片地板变黑 | 场景（Claude 的错） | 描边把斜着看的地板当成了轮廓线 |
| 镜头一贴墙全糊 | 场景 | 泼溅生成的墙只有远看清楚；Claude 还把走廊宽度量错 1 米，镜头直接进了墙里 |
| 镜头闪烁跳来跳去 | 交互 | 身后被挡就自动拉近，拉近又被挡 |
| 拔剑时剑穿袖子、全屋线条变红 | 交互 | 妖化特效作用到了整个画面 |

结尾落一句：车翻完了，现在能玩，链接在简介。
**好处**：最好笑，用户爱看翻车。**风险**：交互构思讲不深，像花絮。

## 方案 C：决策版：「我在里面到底做了什么」

**一句话**：AI 干活，我做判断。讲 5 个关键选择，每个选择配一个对比画面。
**长度**：3~4 分钟。用你看业务和代码的方式讲，不讲身份标签。

| 选择 | 当时的两条路 | 怎么定的 | 画面 |
|---|---|---|---|
| 1 先做哪一步 | 先批量出素材 / 先验证最可能失败的 | 画风能进 3D 再批量做 | 药郎 v1 样片 |
| 2 要不要玩法 | 探案解谜 / 只逛不玩 | 场景和玩法拼不到一起，砍掉玩法 | 探案版天秤 → 游览版地图 |
| 3 场景怎么搭 | 全用泼溅 / 积木 + 少量泼溅 | 并排对比四个机位再定 | 积木 vs 泼溅对比图 |
| 4 去哪几个地方 | 按还原难度、积木复用、粉丝认得打星 | Claude 推荐坂井家，我选了万屋 | 七个地点打分表 → 万屋 |
| 5 AI 怎么分工 | 一个对话做到底 / 开好几个线 | 总指挥 + 场景、角色、文案、剪辑几条线 | 分工表、多个会话窗口 |

翻车穿插在每个选择后面当证据（比如选择 3 后面接"贴墙全糊"）。
**好处**：最有你自己的东西，和其他"AI 做游戏"视频不一样。**风险**：偏理性，开头要用好笑的画面钩住人。

---

## 方案 D：系列版：拆成 4 期短视频

| 期 | 标题方向 | 长度 | 核心画面 |
|---|---|---|---|
| 1 角色篇 | 药郎是怎么一点点"活"过来的 | 1.5~2 分钟 | v1 → v2 → 走路三版 → 拔剑 |
| 2 场景篇 | 一张图生成房间 vs 用代码搭房间 | 1.5~2 分钟 | 泼溅、积木对比、万屋、坂井家 |
| 3 交互篇 | 为什么把解谜游戏改成了逛景点 | 1.5~2 分钟 | 探案版 → 地图长卷 → 观景点、拍照 |
| 4 翻车篇 | 方案 B 的精简版 | 1 分钟 | 翻车集 |

**好处**：每条都短，可以连着发，素材分得开。**风险**：要连续剪四条，单条的完整感弱。

## 我的建议

先发 **B**（翻车版）当引流，再发 **C**（决策版）当正片。A 的内容大部分已经在 C 和开发日志 01 里了。

## 要补拍或补录的

- 游览版实录：从地图长卷进万屋、走到观景点、拍照、按 X 拔剑（网页版，录屏）
- 修好后的画面：和翻车集一一对应（药箱、徳次、冲刺、拔剑），做前后对比
- 多会话分工画面：几个会话窗口并排（C、D 要用）
- 你的口播：每版开头和结尾各一段

## 要你定的

1. 选哪版（或哪两版组合）？
2. 时长上限多少？
3. Claude 翻车这部分讲多少：点到为止，还是单独成段？
